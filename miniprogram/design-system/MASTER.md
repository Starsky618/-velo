# Design System: VELO · MASTER

> **真相源声明**：本文件是 velo 小程序全部 UI 的唯一真相源。改样式先改这里，再改代码；页面级偏差写 `pages/<页面>.md`（存在即覆盖本文件对应项）。
> 状态：**v0.1**（2026-06-12 建 / 色板与签名元素待第一仗真机验收定版）。
> 出身：frontend-design skill 首次真实运行产物；现状病灶有 grep 实证（见 §10 修复账）。

## 1. Design Read（这是给谁的什么东西）

**velo 读作：训练与社交数据工具，给对数据严肃、对器材审美敏感的公路车骑手用。气质是「码表驾驶舱 × 车队涂装」——精密仪器的克制，加一道竞速的血色。不是消费 App 的甜美感，不是健身 App 的鸡血感。**

受众的审美否决权（这些覆盖一切美学偏好）：
- 户外强光下可读：正文对比度不妥协，数据数字永远高对比
- 骑行后疲劳状态下看数据：层级必须一眼分明，不许让用户找
- 字段缺失整块隐藏，**永不显示 "-" 占位**（Tim 拍的永久判例）
- **正式版禁止小字备注/提醒**（Tim 拍）：解释靠结构与折叠，不靠小字

## 2. 三旋钮（全局档位）

- **布局活泼度 VARIANCE: 4/10** —— 数据工具不该 artsy。秩序为主，活泼度集中花在签名元素（§3）上
- **动效强度 MOTION: 3/10** —— 全局静水。大动效白名单只有两个时刻（§7）
- **信息密度 DENSITY: 7/10** —— 骑行数据天然密集，velo 是驾驶舱不是美术馆。用密度传达专业，用层级避免压迫

## 3. 题材锚定（distinctive 的取材清单）

从公路车自己的世界取材，不从"运动 App 一般长什么样"取材：

- **码表面板**（Garmin/Wahoo）：等宽数字、数据网格、黑底高对比的仪表语言
- **碳纤维与金属器材**：冷调深灰、哑光、精密
- **车队涂装逻辑**：整车克制，只有一道高饱和色带——这就是 velo 的 accent 用法
- **环法荣誉文化**：黄衫/圆点衫=成就的颜色语言，徽章感（用于 PR/开奖/荣誉场景）
- **功率训练区间惯例**（Z1-Z7 渐进色）：训练图表的专业语言，骑手熟识

**签名元素（每页唯一的 boldness）**：成绩卡 / 战报卡的「码表面板」语言——等宽大数字 + 紧凑数据网格 + 一道竞速红。这是被分享到群里的脸面，全部大胆预算花在这里；卡片之外的界面保持仪器般安静。

## 4. 色板（名字 + 值 + 角色）｜v0.1 待真机定版

- **Paper** `#F6F6F4` — 页面底色（中性灰白，刻意避开奶油族）
- **Surface** `#FFFFFF` — 卡片/表面
- **Carbon** `#1B1C20` — 主文字、大数字（碳纤维近黑，非 Tailwind `#111827`）
- **Slate** `#66676F` — 次级文字、标签、单位
- **Hairline** `#E9E9EC` — 分隔线、描边
- **Race Red** `#E03A33` — **唯一 accent**：主按钮、当前态、强调数据、成绩卡色带（收编并替换现存两种红）
- **Gain Green** `#12996B` — 语义色：PR/提升/达成（收编现存湖绿调性）
- **Amber** `#D97A00` — 语义色：疲劳/风险提示（收编现存橙，降饱和）

锁定规则：
- **一页一 accent**：Race Red 之外不许出现第二个强调色系
- 语义色只用于语义（成就/警示），永不当装饰；数据"下降/中性"用 Slate，不用红（避免 accent 语义污染）
- 深色场景（开奖动画、码表风面板）：底 `#141519`，文字反白，Race Red 不变

## 5. 字体与数字

- **字族**：系统字（小程序平台约束下的诚实选择；自定义字体 wx.loadFontFace 体积成本不值——velo 的字体性格不靠字族，靠下面两条）
- **字重极端对比**：标题/大数字用 700-800，正文 400，标签 400 + Slate 色——禁用 400 vs 600 的怯懦对比；层级靠字重和颜色，不靠堆字号
- **数据数字 = velo 的字体签名**：所有指标数字（功率/心率/速度/里程/时长）用等宽数字栈 `font-family: 'SF Mono','DIN Alternate',monospace` + `font-variant-numeric: tabular-nums`——码表感的来源，且列表中数字对齐不跳动
- 数字与单位分离排版：大数字 + 小单位（`287` <small>W</small>），单位用 Slate

## 6. 形状与海拔

- 圆角三档：**4rpx**（徽章/进度条/小标签）/ **12rpx**(按钮/输入/图表容器) / **24rpx**（卡片）——禁止档外自由发挥
- 海拔纪律：卡片只在"内容确实是一个可分享/可点击的整体"时用；**数据列表用 Hairline 分隔线，不用卡片堆叠**（DENSITY 7 的呼吸全靠这条）
- 阴影只允许一档：`0 2rpx 12rpx rgba(20,21,25,0.06)`，且只给悬浮元素（弹层/吸底按钮）

## 7. 动效预算

- 全局默认：150-250ms，ease-out 进 / ease-in 出；只动 `transform`/`opacity`
- **大动效白名单（仅两个时刻）**：①开奖动画（velo 唯一的庆典，可以放肆）②PR/徽章揭示（克制的一次性 stagger）
- 禁区：列表滚动动效、页面转场花活、装饰性循环动画、>400ms 的任何过渡

## 8. Anti-Patterns（velo 特化封杀清单）

- 奶油底"高级感"（`#f7f3ea` 族）——已在现网，见修复账
- Tailwind 默认灰阶裸用（`#111827`/`#6b7280`/`#374151`）——用 §4 定制灰阶
- 第二强调色 / 多红并存
- "-" 占位符、"暂无XX"字样（字段缺失 = 整块 wx:if 隐藏）
- 小字备注/来源标签/提醒文案
- emoji 当图标（用 SVG：lucide via image 是既有惯例）
- 三等分功能卡片行；装饰性编号
- 套话文案（"开启骑行新篇章"类）；假整数；"不是X而是Y"句式（route 内容铁律同源）

## 9. 平台约束备忘（小程序特有事实）

- rpx 体系：设计稿 px×0.879→rpx 惯例（约骑原型还原实证）
- canvas 图表容器用 `hidden` 控制显隐，**禁 `wx:if`**（陷阱 #17：canvas 2d node race，90% 机型不渲染）
- 图标：lucide SVG 经 `<image>` 引入（约骑原型既有惯例）
- WXML 不能调数组方法；数据加工在 js 层 setData 前完成
- 海拔曲线等 canvas 绘制：唯一绘制时机在折叠模块展开时（route-detail 既有惯例）
