# VELO Sans web subset

The `velo-sans-zh-*-v1.woff` files are renamed, page-specific web subsets of
Adobe Source Han Sans CN 2.005R.

- Source: <https://github.com/adobe-fonts/source-han-sans/releases/tag/2.005R>
- Original files: `SourceHanSansCN-Regular.otf`,
  `SourceHanSansCN-Medium.otf`, and `SourceHanSansCN-Bold.otf`
- License: SIL Open Font License 1.1; see `OFL.txt`
- Scope: glyphs used by the visible Chinese public homepage copy as of
  2026-07-29, plus the Latin letters, digits, and punctuation needed by that
  copy

The derivative family name is `VELO Sans` so the modified subsets do not use
Adobe's reserved `Source` font name.
