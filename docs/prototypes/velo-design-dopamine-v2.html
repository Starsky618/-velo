SCREEN 05这版改了什么（给 Tim 的设计说明）

v1 → v2

v1 的病不在颜色在排版：均匀堆叠=没有留白。v2 用「极端对比」重写韵律——超大与超小、大空与大密。
28:41Barlow Condensed
赛事计时牌/号码牌谱系字体
小程序可加载（数字子集 ~20KB）
字体
系统字 → 窄体计时牌大数字（Barlow Condensed），中文重黑体标题，中英混排做杂志感
背景
深底世界观撤掉 → 暖白大留白；背景图案 = velo 自己的海拔剖面线浅浅呈现（数据即装饰，竞品抄不走）
排版
150px 超大主数字 + 细行数据条的极端对比；去卡片化（细线分隔代替卡片堆叠）；超大浅色英文 ghost 字做空间层次
成绩卡
码表面板 → 完赛证书：细线框 + 编号 + 荧光 PR 印章 + 真实海拔剖面收尾
Volt 用法
从"主角"退为"点睛"：PR 斜条带、印章、高亮笔、tab 指示——黑字荧光底只在关键奖赏处出现
按钮
荧光大按钮 → 碳黑底 + 荧光字（更收敛更贵），直角化（r=2px，证书/号码牌的利落）
