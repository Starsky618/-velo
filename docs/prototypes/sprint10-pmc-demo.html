为什么这么建议

这里先用人话解释，不强迫用户懂 PMC 三条线。

1

周六那次爬坡让疲劳明显升高

那次骑行 TSS 115，是本周最重的一次。它让短期疲劳升得很快。

2

体能在变好，但还需要恢复

体能像慢慢涨的水位，疲劳像突然下的大雨。今天大雨还没退。

3

今天的目标不是变强，而是不把身体压垮

轻松骑能保持习惯，也给明后天留出更好的训练空间。

数据从哪来

后端先算清楚数字，大模型只负责把数字讲成用户能执行的话。

1

每次骑行先算 TSS

用本次骑行时长、标准化功率、当时锁定的 FTP 算出训练分数。

2

把每天的 TSS 加起来

一天多次骑行就合并成当天总压力；没有功率或 FTP 的活动先不参与。

3

算三种状态

体能看 42 天慢变化，疲劳看 7 天快变化，今日状态 = 体能 - 疲劳。

后端公式草案： TSS = 时长秒 × NP × IF / (FTP × 3600) × 100 IF = NP / FTP 今日状态 = CTL - ATL

大模型放在哪里

大模型不是裁判，它像一个会说人话的教练助理。

算

数字由后端算

TSS、体能、疲劳、今日状态这些必须可复查，不能让模型自由发挥。

写

模型写 4 段建议

标题、综合分析、训练决定、风险提醒。没数据就老实说数据不足。

禁

不假装知道身体恢复

现在拿不到 HRV、睡眠、静息心率，所以不能写“你昨晚恢复很好”。
