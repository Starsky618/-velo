产品落地链路（后端零改动）：开奖页 / 活动详情点「生成水印照片」→ 从相册选当次骑行照片（wx.chooseMedia）→ 小程序 canvas 把数据 + 轨迹线 + VELO 标合成到照片上 → 保存到相册 / 直接发群。轨迹线从该次活动的 GPS 数据生成（本样本为手绘示意）；用户没拍照片时，回落到路线官方封面或纯色底。

velo vs Strava 水印的两点差异：① 功率数据——Strava 水印只给距离/爬升/时间，velo 给 NP 功率，对训练党是更硬的炫耀；② Volt 荧光轨迹线 + 品牌点，替代 Strava 橙。
