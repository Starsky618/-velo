## 一、为什么对标 Letterboxd 而不是 Strava

直觉上 velo 该对标 Strava——同样是骑行、都有 GPS 数据、都有赛段。但**产品结构上 velo 和 Letterboxd 更像**。

| 维度 | Strava | Letterboxd | velo(按战略) |
|---|---|---|---|
| 核心动作 | 记录骑行数据 | 记录看过的电影 | 记录骑行数据 |
| 数据结构 | 每次骑行 1 条 | 每部电影 1 条 | 每次骑行 1 条 |
| **身份载体** | **运动表现**(时间/距离/功率) | **观影品味**(看过什么) | **骑行身份**(去过哪 + 骑得像谁) |
| **社交单元** | kudos 点赞 | 评分 + 评论 | 赛段重合 + 地理重合 |
| **发现机制** | 排行榜(竞争) | 品味相似推荐 | 骑行指纹匹配 |
| **商业模式** | 订阅 $80/年(功能付费) | 订阅 ~$20/年(功能轻) | 未定,v1-v4 全免费 |
| **目标用户** | 严肃运动员(表现导向) | 影迷(文化归属) | 严肃骑手(**身份 + 社交**) |
| **用户数** | 150M+(全球) | 17M(全球,垂直深度) | 0(待增长) |
| **估值** | $2.2B | ~$50M (Tiny 2023 收购) | — |
| **团队规模** | 数百人 | 20 人左右 | 3 人 |

**Strava 和 velo 的真正差异**: Strava 是"严肃运动员的表现追踪工具",velo 是"严肃骑手的身份图谱 + 社交网络"。

**Letterboxd 和 velo 的真正同构**:
- 两者都是**垂直兴趣社区**(不是通用社交)
- 两者都用**用户的行为数据作为身份载体**(看过的电影 / 骑过的路)
- 两者都**靠品味/风格相似建立连接**(不是 follow 通讯录)
- 两者都对标过一个"头部数据工具"但走了不同路(Letterboxd vs IMDb / velo vs Strava)

**结论**: 讲 velo 用 "Letterboxd + 骑行" 类比 **比讲 "Strava 中国版" 准确 5 倍**。前者讲清产品本质,后者错误暗示 "velo 只是 Strava 的本地替代"。

## 三、Letterboxd 的 14 年故事

### 2011: 从"加拿大版 YouTube"到"Goodreads for Movies"

创始人 Matthew Buchanan 和 Karl von Randow 是新西兰科技圈老炮。2003 年他们尝试做新西兰短片分享网站(类似 YouTube 雏形),失败。

8 年后,他们重新思考: "我们自己最需要什么工具?" 答案: **追踪自己看过的电影 + 和朋友比较品味**。IMDb 太数据化,Rotten Tomatoes 太面向专业影评人。普通影迷需要一个"电影版 Goodreads"(Goodreads 是图书的标记 + 打分 + 书单平台)。

2011 年 10 月在 Brooklyn Beta 大会上发布私测版,定位明确: **cinephile(影迷)的社交平台**。

### 2012-2016: 慢热期 + 小而美哲学

前 5 年增长缓慢(2011 上线到 2020 累计只有 180 万用户,年均 20-40 万)。但这 5 年建立了三个**长期护城河**:

1. **功能极度克制**: 只做电影(不碰 TV),只做评分评论(不做视频 UGC),只做 watched/watchlist 标记(不做社交通讯录)
2. **品味门槛**: 早期用户都是硬核影迷,带来的内容质量极高,形成"在这里打差评会被骂"的氛围
3. **小团队长期独立**: 没融大钱,没被 VC 压着增长,按自己节奏演化

### 2017: 关键转折

2017 年用户数几乎翻倍(评分数 1600 万 → 3000 万)。原因是 **IMDb 关闭了 message boards**(社群讨论区),大量影迷迁移到 Letterboxd。

**这一事件对 velo 的启示**: **你不需要主动"抢"用户,你需要做好产品等对手犯错**。IMDb 关闭讨论区 → 影迷流失 → 流到 Letterboxd。Strava 对中国用户的地图偏移 / 订阅门槛 / 无微信整合 → 骑手痛苦 → velo 接住。

### 2020-2022: 疫情爆发

COVID 推动 Letterboxd 从 180 万用户飙到 2021 年 410 万(2 年 2.3 倍)。居家期间大家狂看电影 + 上网分享,Letterboxd 是天然承载平台。

**2022-07 突破 10 亿部电影登记**,距离上一个里程碑(1 亿,2017)仅 5 年。

### 2023-2024: 被 Tiny 收购 + 商业深度

2023 年加拿大投资公司 Tiny 收购 Letterboxd 多数股权。这不是传统 VC 压"高增长高退出"的路径,Tiny 的风格是**"买下好公司长期运营"**(类似 Berkshire 的风格)。

收购后 Letterboxd 开始:
- 拓展影院 showtimes 显示(2023-12)
- Video Store 数字租片平台(2025-11)
- 更深的电影产业合作(独立片发行商把 Letterboxd 当核心营销渠道)

**Letterboxd 现在的状态**: 17M 用户、稳定增长、不追求上市、商业模式多元(Patron + HQ + Video Store + 合作)、团队 20-30 人。**这就是所谓"小而美 sustainable"的教科书样本**。

## 四、Letterboxd 做对的 5 件事

### 4.1 第一天就是社交,不是工具

Letterboxd 从上线第一天就把"你看过的电影"自动变成社交信号: 你的主页是"你的观影史",别人可以看、可以跟,可以讨论。

它**没有**走过"先做工具然后加社交"的路。2011 年刚上线时,即使只有 1000 用户,社交机制已经齐全(评分 / 评论 / 关注 / 活动流)。

**velo 的借鉴**: 不要搞"先 v1-v3 做工具,v4 加社交"这种分期,从第一天就把上传 = 分享、活动 = feed。Strava 是先工具后社交,一直被吐槽社交浅;Letterboxd 是先社交再工具,成了垂直社交的标杆。**velo 要走 Letterboxd 的路**。

### 4.2 四部最爱电影 + List 机制

Letterboxd 让每个用户主页放 **"4 部最爱电影"**(top 4 favourites)。这是天才的产品设计:

- 4 不是 5,是 Letterboxd 特意选的数字。5 太多,3 太少,4 正好能展现"品味"又不啰嗦
- 进入别人主页,3 秒看懂"这人是什么类型影迷"
- 成为社交破冰器: 两人刚互相发现时,先看对方 4 部最爱,立刻知道是否对味

**List 机制**(用户创建电影单) 是另一个绝招:
- "我最爱的 40 部公路片"
- "看这些之前别学电影"  
- "只有文青懂的冷门佳作"

这些 list 本身成为独立内容,带来 SEO 流量 + 社群讨论 + 品味展示。

**velo 的借鉴**:
- **"4 条最爱赛段"** 应该成为 velo 个人主页核心元素——和 Letterboxd 完全同构
- 用户可以创建 **"骑行路书"**(类似 list): "太原经典老炮环线 5 条"、"北京郊野周末骑行 TOP 10"、"爬坡虐腿必去"。每条路书是一个内容单元 + 社交触点

### 4.3 不做 app 绑架,不收硬件费

Letterboxd **只做 web + 移动 app**,**完全不碰硬件 / 流媒体 / 影院 ticketing**(和第三方合作)。他们自己定位:**"between filmmakers, distributors and the studios"**(在创作者、发行商、影院之间做"润滑剂"),不成为任何一方。

这让 Letterboxd 保持**独立性和中立性**——独立电影人、大制片厂、流媒体平台都把 Letterboxd 当重要渠道,不怕被"拥抱"。

**velo 的借鉴**:
- 不做码表(iGPSport / Magene / XOSS / Garmin 都是硬件合作伙伴)
- 不做实时导航(ADR-010,跳转高德)
- 不做装备电商(v8+ 远期考虑,当前 0)
- 定位: **"在骑手、车店、赛事方、装备品牌之间做身份图谱 + 社交层"**

### 4.4 小团队长期独立

Letterboxd 服务 1700 万用户,团队只有 ~30 人(20 全职 + 10 兼职/freelance)。**人均服务 57 万用户**。

这个效率来自:
- 功能克制(没有功能爆炸就没有维护负担)
- 技术栈稳定(Ruby + PostgreSQL + AWS,10 年没换)
- 社群自运营(用户互相推荐,不需要大规模运营团队)
- 没有融资压力(不需要为"本季度增长"赶工期)

**velo 的借鉴**:
- **不赶 KPI 增长**: v1-v4 已证明 3 人团队能做完整后端 + 小程序
- **长期独立运营备用选项**: 如果 velo 增长到 10 万用户 + 年营收 1000 万,**可以选择不融资做 sustainable 小公司**,不必追求 IPO
- **功能克制**: 不要什么都做,不要走 "Strava 路线" 扩展到 40+ 运动类型

### 4.5 用户身份是 Letterboxd 本身

2024 年记者观察到的现象: **Letterboxd 三色帽子**(商品化周边,上面是 Letterboxd logo 三色点点) 成为"懂电影"的社交标识。年轻影迷戴着这个帽子走在街上,知道的人会主动搭话。

这是**品牌升华为身份标签**的极致表现——用户不只是"用 Letterboxd 的人",而是"认同 Letterboxd 价值观的人"。

**velo 的借鉴**:
- 长期目标: velo 小程序码 / velo 车衣 / velo 水壶套 等周边成为 "真骑公路车的人" 的社交标识
- 核心用户画像调研: 你是公路车骑手,看到别人车上贴 velo 车标会不会主动搭话?(如果会,velo 就在做 Letterboxd 那个成功路径)

## 五、velo vs Letterboxd 的产品同构

直接对照表,帮你脑子里建立映射:

| Letterboxd 核心元素 | velo 对应元素 |
|---|---|
| **每部电影一个页面** | **每条赛段一个页面** |
| 电影页: 评分 + 评论 + 列表出现数 + 看过的人 | 赛段页: 排行榜 + 评论 + 实景照片 + 骑过的人 |
| **个人主页: 观影史 + 4 最爱 + list** | **个人主页: 骑行热图 + 4 最爱赛段 + 路书** |
| **List**(用户创建的电影单) | **路书**(用户创建的路线推荐) |
| **review**(用户写的影评) | **赛段笔记**(用户对赛段的评价,含路况 / 避坑 / 打卡机位) |
| **diary**(按月/年的观影记录) | **骑行日历**(按月/年的骑行记录) |
| **year in film**(年终个性化报告) | **year in ride**(年终骑行总结报告) |
| **following**(关注你感兴趣的人) | **following**(关注骑得像你的人) |
| **stats**(订阅独享的深度数据) | **velo 不藏**,深度数据全免费(差异化策略) |
| **HQ**(电影院 / 发行商账号) | **车店 / club / 赛事方账号**(v6+) |

## 六、Letterboxd 身上 velo 必须抄的 3 件事

挑选最有 velo-adoption 价值的 3 条:

### 6.1 "4 最爱赛段" 立刻抄

**Action**: PRD v5 加入"4 最爱赛段"功能到个人主页
- 用户手动选择 4 条
- 显示顺序可拖拽
- 支持查看别人主页的 4 最爱
- 这是产品上最快能实现的"Letterboxd 式身份表达",工作量 2-3 天

**效果**: 两个骑手在 velo 上互相发现时,看对方"4 最爱赛段"1 秒判断是否对味,决定是否关注。这是**破冰加速器**,对"一线城市原子化骑手渴望连接但不敢线下搭话"画像致命。

### 6.2 "赛段笔记 + 实景墙" 作为 UGC 容器

**Action**: 每条赛段详情页加 UGC 区
- 骑过的人可以写"笔记"(路况/坡度/拍照机位/补给点/避免时段)
- 可以贴照片(GPS 校验过来自这条赛段)
- 笔记按 kudos(或 velo 内叫"赞同数")排序
- 对应 Letterboxd 的 **review 机制**

**效果**: 赛段从"数字排行榜"升级为"微型垂直社区"。新骑手打开东山赛段,不只是看到"最快 14 分钟",而是看到"老张写的雨后路况 / 老王拍的山顶日出机位 / 老李提醒的修路避开时段"——**这是 Strava 没做的,是 velo 的核心差异化**。

### 6.3 "year in ride" 年终报告

**Action**: 每年 12 月底给用户生成个性化报告
- 总里程 / 总爬升
- 最爱赛段 TOP 5(按骑行次数)
- 新解锁的赛段(今年第一次骑)
- 最快一次 / 最远一次 / 最累一次
- 对比去年增长百分比
- 社交互动: "你今年被点赞 X 次"
- 可分享到朋友圈(关键)

**效果**:
- 年底是**骑行 KOL / 车店 / club 领队**在朋友圈集中分享内容的时候
- 每一份 velo year in ride 分享 = 1 次小程序曝光 = 一个潜在新用户
- 对照 Strava 的 "Year in Sport" 也是年末传播大事件

**工作量**: 后端算数据 + 前端做分享卡片(前端 Canvas),2 周即可

## 七、差异和不抄的地方

### 7.1 Letterboxd 订阅模式 velo 不直接抄

Letterboxd 订阅 $19-49/年,主要卖"去广告 + 高级统计 + 优先支持"。**这套中国用户不买账**(广告没有直接痛感,统计功能国内多数 app 默认免费)。

velo 走中国市场特色的 **outcome-based 商业化路径**(训练营 / 精英社群 / 导购联运),不做功能订阅(见 ADR-009 + PRD)。

### 7.2 Letterboxd 综合电影 velo 不综合运动

Letterboxd 覆盖所有电影(大片 + 艺术片 + 短片 + 动画),因为电影内在就是"所有叙事片共用一套评价系统"。但**骑行 ≠ 跑步 ≠ 徒步 ≠ 游泳**,每项有独立的赛段定义、训练逻辑、社群文化。

velo **不模仿 Letterboxd 的"横向全覆盖"**,坚持公路车垂直(见 ADR-007 + PRD)。

### 7.3 Letterboxd 全球化 velo 先本土化

Letterboxd 只 35% 用户在美国,极强国际化(190+ 国)。velo 反过来: **先做深中国一线/新一线城市**,海外是 v10+ 的事。

### 7.4 Letterboxd 没有"实时竞技" velo 有赛段 KOM

Letterboxd 用户看电影是独立体验,不涉及"谁看得快"(你看完电影用了多少时间与我无关)。但骑行有 KOM 机制,velo 保留 Strava 式竞技。

这是 **velo = Letterboxd + Strava 的混血优势**。

## 八、"velo 就像 Letterboxd" 的 1 分钟融资模板

给 VC / 合伙人 / 种子用户讲 velo 用这个脚本:

---

> "velo 是**公路骑行版的 Letterboxd**。
> 
> Letterboxd 是什么?17 年前创立,今天全球 1700 万影迷在用。用户记录自己看过的电影,自动生成个人观影史 + 品味画像,别人可以看你的 4 最爱、你写的影评,基于品味相似互相发现。从独立电影人到大导演都在用。估值几十亿,被 Tiny 2023 年收购长期独立运营。
> 
> velo 做的是同样的事——只是把'看电影'换成'骑公路车'。
> 
> 你上传每次骑行,自动生成个人骑行热图 + 赛段成绩 + 风格标签。别人在你主页看到你常骑哪 4 条赛段 + 你对这些赛段的笔记,3 秒判断'这人也是严肃骑手,跟我骑得像'。
>

> 
> 对比 Strava: Strava 是 80% 工具 + 20% 社交,velo 做 80% 社交 + 20% 工具。Strava 从不进中国(四个结构性死穴),velo 抢中国严肃骑手。
