# Komoot 对标

> **这份文档给谁看**: Tim 本人 + 团队/VC 讨论"velo 为什么不做路线规划"时的参照。
>
> **一句话核心论点**: **Komoot 是 velo 刻意不走的那条路**。路线规划是深坑,Komoot 靠它建立了 4500 万用户,但也因为深度投入被 Bending Spoons 以 3 亿欧元"套现式"卖出。velo 走 Letterboxd 路线,把"规划"外包给高德,把力气用在社交身份上。
>
> 读完这份你应该能: (1) 理解 Komoot 的真实规模和商业结构 (2) 解释 "velo 为什么不学 Komoot" (3) 防御 VC 可能提的 "你不做路线规划不完整"。

## 一、Komoot 核心数据

### 规模(2024-2025)

| 指标 | 数值 | 来源 |
|---|---|---|
| 全球用户 | **45M+** | Komoot 官网 2025 宣称 |
| 内骑手估计 | 约 4M 骑行用户(其中 1.8M 山地车) | Bikerumor 2024 |
| 主要市场 | 欧洲(德/法/意/西/英/荷)+ 北美 2014 扩展 | |
| 总部 | 德国柏林(**不是**新西兰或美国) | |
| 员工数 | ~150 人(至 2024) | |

### 商业模式

**核心结构**: 免费基础 app + **地区解锁** + **Premium 订阅**(2024 年改版)

- **免费**: app 本身 + 1 个免费地区 + 基础路线规划
- **地区解锁**: €3.99/地区(约 30 欧元 / ¥240 全球)
- **World Pack**(**一次性** €29.99): 全球所有地区解锁。**这个一次性付费**是 Komoot 独特招数
- **Premium**(2024 新增,订阅制): 年费约 €59(或月费 €7),额外提供运动专属地图、多天规划、天气+顺风、离线语音导航

2024 年改版后,用户反弹强烈——很多曾经免费的功能(如详细坡度、路面类型显示)转到 Premium,和 Strava 同类操作。

### 被 Bending Spoons 收购(2025-03-20)

**关键事件**: 2025 年 3 月 20 日,意大利私募股权公司 **Bending Spoons** 以约 **3 亿欧元** 收购 Komoot。

收购后立即:
- **裁员**: 150 员工裁减至约 30 人(裁员 80%)
- **价格上涨**: Premium 订阅涨价
- **功能转付费**: 更多免费功能转 Premium
- **社群强烈反弹**: Bikepacking.com 7 月长文《When We Get Komooted》批评私募股权"榨干社群建立的公地"

**BIKEPACKING.com 原话**(2025-07):

"6 名创始人违背了对公司长期承诺的誓言,出卖了约 150 名员工、数百万活跃用户和这项深受喜爱的服务,3 亿欧元交易中占据大头...用户和员工都被'Komoot 式背叛',被资本的算法带偏。"

"Komoot 的领导层由增长驱动,开发聚焦在推动注册的功能,也包括一些不光彩的手段——比如用算法生成的几千个粗糙路线页面霸占搜索引擎结果。高级用户和大使的反馈长期被忽视。到 2024 年这个平台在欧洲可能已经接近有限用户上限。**这次出售看起来是在欧洲增长不可避免停滞之前的现金套现**。"

这个故事对 velo 极重要——**路线规划这条路的商业天花板已经被 Komoot 验证了**。

## 二、Komoot 的 15 年故事 + 2025 被 Bending Spoons 收购

### 2010-2014: 柏林小团队起步

Komoot 由 **Markus Hallermann** 等 6 人于 2010 年在德国柏林创立。最初做成"骑行 + 徒步 + 跑步的路线规划 app",基于 OpenStreetMap 数据 + 自研路线算法。

2014 年完成 160 万美元种子轮(Schindler Private Ventures + 德国地方基金),同年扩展到美国市场。

这一阶段的核心产品决策: **专注路线规划 + 离线导航**,不做社交(不像 Strava)。

### 2015-2022: 欧洲成为骑行/徒步路线规划事实标准

这 7 年 Komoot 在欧洲**横扫**——特别是德国、法国、意大利的自行车旅行和徒步市场。关键功能:

- **多运动支持**: 不只是骑行,覆盖 road / gravel / MTB / hiking / running
- **Highlights**: 用户可以在路线上标记"美景点 / 咖啡馆 / 休息点",成为社群贡献的 POI 数据库
- **Tours**: 用户分享的完整路线,其他人可以复用
- **Discover**: 在欧洲达到"临界密度"后,Komoot 能根据区域热图自动推荐 Tours
- **品牌合作**: Rapha 女性骑行活动 / Specialized 电动自行车集成 / Transcontinental 超远距离骑行赛事官方合作伙伴

### 2023-2024: 欧洲饱和迹象 + 产品变味

2024 年迹象开始出现:
- 欧洲增长放缓(**欧洲已经接近饱和**)
- 亚洲和南美洲扩展困难(OpenStreetMap 数据在这些地区覆盖差)
- Premium 订阅转型,激怒免费用户
- 产品开始"SEO 霸屏"式营销(自动生成低质量路线页面,搜索引擎刷量)

### 2025-03: Bending Spoons 3 亿欧元收购 + 大裁员

**Bending Spoons** 是意大利的"AI 与数字产品收购方",以"买下好公司 + 优化运营 + 榨干现金流"出名,收购过 Evernote、Meetup、Filmic Pro 等。

收购 Komoot 后做法:
1. 150 员工裁减至约 30 人
2. 涨价 + 功能转 Premium
3. 社群抱怨被忽视
4. 原创始人团队大部分离开

**Komoot 作为"路线规划 + 大体量欧洲用户"的样本公司,15 年后的退出估值 3 亿欧元**。对比 Strava 2026 IPO 估值 30 亿美元——**差 10 倍**。两个对比说明:**社交 >> 工具,在商业估值上的倍数差**。

## 三、Komoot 做对的 4 件事

### 3.1 路线算法 + OpenStreetMap 数据组合

Komoot 的路线算法是业界公认最强之一。它不是简单"起点到终点最短路径",而是考虑:
- 你选的运动类型(公路车 vs 山地车 vs 徒步)
- 路面偏好(柏油 / 砂石 / 土路)
- 坡度容忍度
- 你的体力等级(1-5)
- 避开高速公路 / 优先官方骑行道
- 添加 Highlights(景点 / 咖啡馆)作为途经点

这让 "规划一条 80 公里环线" 从"人工在地图上画 1 小时"变成"选参数 + 10 秒"。

**velo 不做这个,因为**: 
- 中国 OpenStreetMap 覆盖差(Tom Allen 2024 文章明确说"OpenStreetMap coverage was also poor where I live"指中国)
- 算法研发成本巨大
- 高德/百度已经做得够好
- 不是 velo 核心差异化

### 3.2 Highlights 机制: 用户贡献的 POI 数据库

Highlights 是 Komoot 的社交元素。用户可以在路线上标记"这里有个绝美观景点"、"这家咖啡店值得停"、"这段路夏天有大量蚊子"。其他人规划路线时,算法会把高评价 Highlights 纳入候选途经点。

本质是**用户贡献的 POI 数据库**,比 Google Maps / Tripadvisor 的数据**更贴近骑行者视角**。

**velo 要抄的部分**: 赛段详情页的 "实景墙" 和 "赛段笔记" 就是 Komoot Highlights 的精神子集(但更聚焦于赛段而非随意路线点),见 Letterboxd 对标 §6.2。

### 3.3 World Pack 一次性买断

Komoot 独特的**一次性付费** €29.99 买断全球地区——这是 **"非订阅制"的商业模式**。很多讨厌订阅的用户愿意付这个一次性费用。

**velo 借鉴**: 商业化路径可以留出"一次性付费"选项(如精英社群终身会员),而不是纯订阅。

### 3.4 品牌合作建立可信度

Komoot 是 Transcontinental Race(超长距离骑行赛)官方路线合作伙伴。同时和 Rapha、Specialized、adidas Five Ten 等高端品牌有深度合作。

这些合作**不是广告**,是让 Komoot 在严肃骑行社群里建立"专业"心智的关键。

**velo 借鉴**: 长期(v5+)要和国内骑行赛事(如八百流沙、环塔拉力赛、银川公路车超级联赛)和装备品牌(国产头部如捷安特、喜德盛;高端如闪电、崔克)做深度合作。

## 四、Komoot 做错或结构性限制的 4 件事

### 4.1 路线规划 = 低粘性场景

路线规划是用户"**偶尔打开**"的功能,不是"每天必用"。典型用户:
- 周五晚: 规划周末骑行(1 次)
- 周末骑完: 导入 Strava(0 次, 因为 Komoot 本身记录)
- 周一到周四: 几乎不打开 Komoot

对比 Letterboxd: 用户**每次看完电影都会记录 + 刷 feed**(接近"每天打开")。
对比 Strava: 用户**每次骑完必上传**(每周 3-5 次)。

路线规划的低频 = 用户粘性低 = **天花板较低**。这是 Komoot 45M 用户但估值 3 亿欧元的原因——用户多但黏性不够。

### 4.2 社交极弱

Komoot 有 Tours 分享和 Highlights 评论,但**没有真实的社交网络**:
- 无 feed(不自动看好友路线)
- 无 kudos 机制
- 无约骑 event
- 无聊天私信
- Tours 评论区冷清

**Komoot 本质是工具,不是社交**。

### 4.3 OpenStreetMap 依赖 = 亚洲扩展困难

OpenStreetMap 在欧洲覆盖极好(德法英荷比利时等地区地图数据丰富),**但中国大陆覆盖差**——中国法律限制众包地图,OSM 在中国的覆盖远低于高德/百度。

这就是 Komoot 至今**从未认真进入中国市场**的原因。和 Strava 进不来中国一样,是**结构性问题**。

### 4.4 被私募股权收购 = 社群信任崩塌

2025 年 Bending Spoons 收购后,Komoot 社群的核心情绪从"喜欢"变成"被背叛"。骑行社群是**信任驱动的**(尤其是对一个 15 年老品牌),一旦信任崩塌,替代品会快速崛起。

**velo 的启示**: 长期运营中**不要让私募股权进入股东结构**。要么保持独立,要么让对齐文化的战略股东进入。

## 五、为什么 velo 不走 Komoot 路线

### 5.1 战略层面

| 维度 | Komoot 路线 | velo 路线 |
|---|---|---|
| 核心场景 | 骑前规划(低频) | 骑后记录 + 社交(高频) |
| 用户粘性 | 周频/月频 | 每次骑行后必用 |
| 估值模型 | 工具 × 用户量(低倍数) | 社交网络 × 活跃度(高倍数) |
| 竞争壁垒 | 算法 + OSM 数据(随时可抄) | 社交图谱密度(一旦形成不可抄) |
| 商业化 | 地区解锁 / 订阅 | outcome-based(训练营 / 社群) |
| 中国可行性 | 差(OSM 数据弱) | 好(微信生态 + 国产码表) |
| 退出路径 | 私募股权套现(Komoot 3 亿) | 社交网络并购或 IPO(Strava 30 亿 / Letterboxd sustainable) |

**明显**: velo 选 Letterboxd+Strava 混合路径,远比 Komoot 路径估值模型更强。

### 5.2 技术层面

做路线规划意味着:
- 全国路网数据(要和高德/百度竞争,打不过)
- OpenStreetMap 中国覆盖不够,要自己补
- 路线算法(要投入 2-3 个全职工程师,团队没这个预算)
- 实时路况(要数据合作伙伴)
- 语音导航(TTS 技术)
- 离线地图(巨大存储挑战)

**每一项都是"专业导航公司"级别投入**,velo 团队 3 人做不了。

### 5.3 用户习惯层面

velo 用户研究显示:
- **严肃骑手用码表(Garmin / iGPSport / 黑鸟)做导航**,不看手机
- **休闲骑手直接用高德**,不会切换到专业 app
- 两类用户**都不会把 velo 当导航 app**

做路线规划 = 浪费资源做用户不想要的功能。

## 六、velo 要从 Komoot 学的 2 个局部

### 6.1 Highlights → 赛段笔记 + 实景墙

Komoot 的 Highlights 是用户贡献的 POI。velo 的等效物是"赛段笔记 + 实景墙"(见 Letterboxd 对标 §6.2)。

**velo 借鉴但改造**:
- 不是任意地点标记(Highlights 那样),而是**绑定赛段**的评论/照片/路况
- 这样避免了 Komoot 的"POI 满地都是,信噪比低"问题
- 同时保留了"用户贡献本地知识"的精神

### 6.2 一次性付费选项

Komoot 的 €29.99 World Pack 一次性买断证明了"**一次性付费在某些人群有需求**"。

velo 未来商业化时,可以考虑:
- **精英社群终身会员**: ¥4999 一次性,承诺永久访问 + 终身社群身份
- **完赛营单次购买**: 不走订阅,按次买
- **Pro 徽章一次性认证**: ¥99 永久,显示在个人主页

比"¥30/月订阅"心智负担低,转化率高。

## 七、VC 可能提的问题和标准答法

### Q1: 你不做路线规划,怎么对抗 Komoot / 高德?

**答法(~1 分钟)**:

"velo **刻意不做路线规划**,理由是三个:

(1) **场景低频**: 路线规划用户"偶尔打开",不是"每次骑车都用"。Komoot 45M 用户估值 3 亿欧元,Strava 50M MAU 估值 30 亿美元——**10 倍差距来自场景频率**。我们选每次骑行都要用的场景。

(2) **做不过专业**: 中国的高德百度已经把地图做到极致,velo 3 人团队做不了更好,不如跳转高德,专注 velo 能做到极致的地方。

(3) **中国特有限制**: OpenStreetMap 在中国覆盖差,Komoot 模式在中国跑不通。velo 的"**骑行后记录 + 社交**"反而在中国比路线规划有机会。

Komoot 2025 年以 3 亿欧元被 Bending Spoons 收购套现,大裁员 80%,社群信任崩塌——**这是路线规划这条路的天花板样本**。velo 不走这条路。"

### Q2: 用户说"velo 没有路线规划不完整",怎么办?

**答法(~30 秒)**:

"velo 提供路线**推荐**(基于骑友骑过的实际轨迹,不是算法生成),用户点'在高德打开'一键跳转导航。

这叫**'做骑行前、骑行后的深度体验,骑行中交给专业地图'**。**用户感知会有短暂适应期**,但一旦理解 velo 的核心价值是社交 + 身份,就不会再期待 velo 做导航了。

参考: Letterboxd 没有流媒体播放功能,但影迷在 Letterboxd 决定看什么、看完回来评分。没有人觉得 Letterboxd '不完整'。**velo 走同样的路**。"

### Q3: 你和 outbase 差异在哪?outbase 也做社交。

**答法(~30 秒)**(详细见 outbase dogfood 分析):

"outbase 做的是 '综合运动 + 泛社交',像 Strava 国产化。velo 做的是 '公路车垂直 + 身份图谱',像 Letterboxd 骑行化。

outbase 扩张到游泳、普拉提、体能训练——这是 pre-PMF 慌乱信号。velo **死扣公路车**,垂直深度远超综合化。

此外,outbase 没有微信生态、没有本地社群信任、没有 Tim 这样的 club 领队 founder——velo 在这些 dimension 上结构性领先。"
