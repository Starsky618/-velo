## 2. 阅读路线图

### 按对手威胁等级

**最直接对手(Tim 必读)**:
- `outbase-dogfood-模板.md` — 唯一正面对抗的对手。Tim 必须 2 周内亲自 dogfood 完成填写。

**全球 reference(做战略决策时读)**:
- `strava-深度解码.md` — 理解为什么 velo 不是"中国版 Strava"。投资人会问"Strava 抄你怎么办",答案的深度论证在这里。

**产品模板(做产品设计时读)**:
- `letterboxd-对标.md` — velo 抄的核心设计(4 最爱 / list / year in ride / 小而美)都在这里。设计师和产品决策前必读。

**反面参考(避坑时读)**:
- `komoot-对标.md` — 工具型产品 + 路线规划场景的陷阱,velo 为什么不做路径规划的深度论证。
- `行者-黑鸟-骑记-失败模式.md` — 中国骑行 app 前辈的集体坟墓。五大失败模式是 velo 战略决策的核心负面约束。

### 按决策场景

**我要融资或向投资人解释 velo**:
读 `strava-深度解码.md` + `letterboxd-对标.md` + `outbase-dogfood-模板.md`(如已填写)。这三份覆盖了"velo 为什么在中国有空位"的核心论证。

**我要设计一个新功能**:
读 `letterboxd-对标.md`(学)+ `行者-黑鸟-骑记-失败模式.md`(防)。一正一反两面参考。

**我在犹豫要不要做 X**(如路线规划、装备电商、综合运动):
读 `komoot-对标.md`(路线规划)+ `行者-黑鸟-骑记-失败模式.md`(电商/综合化)。历史已经给了答案。

**我要理解 outbase 的真实威胁**:
先读 `outbase-dogfood-模板.md` 学"应该观察什么",然后**亲自 2 周使用** outbase,填写 checklist,得出结论。这是其他文档无法替代的唯一路径。

**我要写 velo 的对外材料**(PR / 媒体采访 / 融资 deck):
读 `letterboxd-对标.md` §5 产品同构表,这是 velo 最有力的定位武器。

## 3. agent 使用指南

agent **不应该默认加载本目录任何文档**。竞品判断的压缩结论已在 `agent-rules/velo-mental-model.md §3 MENTAL-COMPETITORS`。

agent 检索本目录的触发条件:

**检索 strava-深度解码.md**:
- 用户或投资人问"Strava 进来怎么办"的具体论证
- 需要"四个结构性死穴"的技术和法律细节

**检索 letterboxd-对标.md**:
- 要设计 4 最爱 / list / year in ride 类功能,学 Letterboxd 的做法
- 解释 velo 的"小而美 sustainable"定位的深度依据
- 讨论"velo vs Strava"的根本差异

**检索 komoot-对标.md**:
- 有人提议做路径规划 → 用 Komoot 的失败论证为什么不做
- 讨论"工具 vs 社交"估值差异 → Komoot vs Letterboxd 的 10x 估值差距论证

**检索 行者-黑鸟-骑记-失败模式.md**:
- 有人提议综合化扩张 / 做硬件 / 做电商 → 用前辈失败模式论证
- 讨论融资策略和拿错钱的风险 → 骑记和野兽的案例

**检索 outbase-dogfood-模板.md**:
- Tim 正在执行 dogfood
- 要基于 dogfood 结果做战略调整
- 讨论 velo 相对 outbase 的差异化

> **核心原则**:战略结论已经在 strategy 和 mental-model 压缩过。agent 检索这里只在需要"完整论证过程"或"具体事实细节"时。

## 4. 竞品监控机制

velo 的战略依赖正确的竞品判断。以下是持续监控的机制:

**每月扫描**:
- outbase(App Store 更新日志 + 社交媒体动态 + 公开用户反馈)
- 行者(版本更新 + 商业化动作 + 收入公开数据)

**每季度深读**:
- Strava(IPO 后 10-Q 财报 / 产品重大更新 / 国际化动作)
- Keep / 咕咚(是否深度进入骑行垂直的信号)

**触发紧急刷新**:
- 任何对手发生重大变动(融资、收购、产品重定位、CEO 更换)
- 有新玩家进入中国骑行社交赛道
- 政策变化(地图合规、数据出境、运动 app 监管)
- 发现本目录的事实性错误

## 5. 新增竞品文档的准则

未来如果要新增竞品分析,遵循以下结构(参考现有文档):

1. **一句话核心论点**(开头必须有)
2. **它是谁**(基本情况 + 真实状态)
3. **它的结构性优势或弱点**(战略层分析,不是 feature 对比)
4. **velo 相对的差异化**(具体 4-6 条,每条独立论证)
5. **对 velo 的战略含义**(结论导向的行动建议)

每份文档 300-500 行为佳。过短信息不足,过长失去深度焦点。
