## 二、Strava 的 17 年故事

理解 Strava **为什么现在长这样**,必须回到它的起源。

### 2009: 骑行社交的灵感

Mark Gainey 和 Michael Horvath 都是哈佛校友 + 划艇队员。他们在哈佛划艇队的训练方式给了他们产品灵感: 运动员每天训练都想知道**"我跟队友比怎么样"**。

他们把这个想法搬到自行车上: 做一个 app,让骑手上传 GPS 轨迹,自动和别人比较,在固定路段("segment",赛段)上比速度。

关键洞察(这也是 velo 要记住的): **竞速是人类天性,但面对面竞速太累——异步竞速(跨天、跨月、跨人)恰好好**。Strava 发明了 KOM(King of Mountain,山王)和 QOM(Queen of Mountain)的概念: 某条赛段历史最快的人被加冕。这个机制让每次骑车都变成"可能夺冠"的游戏。

### 2010-2015: 从骑行到跑步的扩张

前 5 年 Strava 主要做骑行。2012 年加入跑步。这个扩张**不是因为产品要变综合运动 app**,而是因为:
- 同一用户骑行又跑步(兼顾的铁三运动员),不可能维护两个账号
- 跑步段(segment)和骑行段可以共享技术栈
- 跑步用户基数远大于骑行

Strava 学到了关键一课: **从单垂类开始,用一个品类建立深度,再横向扩**。2012 年加跑步,2020 年代才加游泳、滑雪、登山——**每扩一个都是在前一个稳固之后**。

### 2015-2020: 订阅转型 + 数据商业化

Strava 之前的商业模式: 免费 + 设备厂商合作(Garmin / Wahoo 预装 Strava)。但这个收入模式不足以支撑增长。

2015 年开始推**订阅(Premium)**。关键争议: 哪些功能收费?

Strava 选了**"分析深度 + 规划工具 + 训练计划"**留给订阅用户。具体是:
- 功率曲线分析(Power Curve)→ 订阅
- 赛段历史成绩对比 → 订阅
- 路线规划 → 订阅
- 训练负荷(Training Load)→ 订阅
- Matched Runs(赛事匹配)→ 订阅

**免费版保留什么**: 基础 GPS 记录 / kudos 点赞 / 社交 feed / club / 单次 KOM 查看。

这个划分的逻辑: **社交元素免费(网络效应不收费才长得起来),深度工具收费(严肃用户愿意付钱提升表现)**。

2018 年后 Strava 还推出了 **Strava Metro**: 把匿名聚合的骑行/跑步数据卖给城市规划部门,用于设计自行车道、优化交通。这是 B2B 数据收入,独立于订阅。

### 2020-2025: 疫情推动爆发 + 全球化

2020 年 Strava 完成 $110M F 轮融资,估值 $1.5B。疫情期间户外运动大爆发,Strava 用户从 5000 万快速涨到 1 亿+。

这一阶段 Strava 开始向**付费墙激进施压**: 原来免费的 leaderboard、route planning、performance analysis 在 2023 年全面转到 Premium。引起用户"nickel-and-diming"(蚕食式涨价)的抱怨——但财务数字证明了策略是对的: **付费转化率虽然只有 2%,但 MAU 5000 万 × 2% = 100 万付费 × $80 = $8000 万/年** 稳定订阅收入。

### 2024-2026: AI 转型 + 收购 + IPO

- 2024-10: Athlete Intelligence 上线(用 ML 把用户训练历史做自然语言总结)
- 2025-04: 收购 Runna(跑步教练)
- 2025-05: 收购 Breakaway(骑行教练)
- 2025-12: 起诉 Garmin 又撤诉(暴露硬件依赖的脆弱)
- 2026-01: 机密 IPO 申请
- 2026-04: Event Browse 上线(我们重点分析,见第 6 节)

**关键**: Strava 从 "数据 tracker" 演化成 "数据 tracker + AI 教练 + 社交平台",**战略从功能工具转向生态**。这是 velo 长期要学的方向——但要注意,**Strava 这一步是在有 5 亿用户 + 已经赚钱之后才做的**,velo 不能提前做。

## 三、Strava 做对的 5 件事 — velo 要学的

### 3.1 把"数据上传"变成"社交货币"

Strava 最伟大的产品发明不是 GPS 追踪(这早就有了),而是**让每次骑行自动变成社交帖子**。

具体机制:
- 用户上传 → 自动发布到 feed(可设私密)
- 好友的 feed 自动看到
- 一键 Kudos(点赞)
- 在 segment 上自动和别人比较,出排名

这套机制的高明之处: **用户"记录自己"的行为,自动变成"社交互动"的原料**。对比 Instagram 需要用户主动拍照发帖,Strava 是"骑完就自动发"——零摩擦。

**velo 的借鉴**: 上传 GPX 要和社交功能深度绑定(默认公开 / feed 自动聚合 / kudos 原生),而不是"先上传,再手动发布"。

### 3.2 Segment + KOM 的天才设计

Segment(赛段) 是 Strava 最核心的知识产权——不是技术,是**产品机制**。

它巧妙地把骑行的"每次都是新体验"这个劣势(不像足球比赛有固定规则),变成"固定赛道 × 无限次重复"的优势:
- 赛段是固定的(例如某条 5 公里上坡路)
- 每次骑经过这段都自动计时
- 历史最快就是 KOM
- 你的个人最快就是 PR

这让骑行从"今天骑了 80 公里"这种抽象数字,变成**"我在东山赛段又快了 3 秒"**这种具体成就。

**velo 已经抄了这个(v0 期就建了 segment 模块)**。但 velo 要做得更深一步: 让 segment 不只是数字排行,而是**聚合点**——评论、照片、路况讨论、实景图都在 segment 上累积(见 ADR-004 + PRD 主文档)。

### 3.3 硬件中立的平台策略

Strava 自己不做硬件。它支持所有主流码表:
- Garmin(Edge 系列)
- Wahoo(Elemnt 系列)
- Hammerhead(Karoo)
- 中国的 iGPSport / Magene / Bryton / XOSS

硬件厂商出码表,Strava 收数据。**一个骑手换码表,只要支持 Strava,数据就能继续累积**。这让 Strava 成为"骑手身份账户",硬件反而变成了"录音笔"。

**velo 要学**: 不要绑死某个品牌,**支持所有码表导出的 GPX/FIT**。velo 目前已做到(任意码表都能导),要持续保持这个策略,不跟硬件厂商深度绑定。

### 3.4 网络效应的冷启动

Strava 冷启动的技巧值得 velo 学:

- **早期只邀请湾区顶级骑手**(2009-2010 只在加州湾区推),制造"严肃骑手用的"心智
- **KOM 作为冷启动钩子**: 新用户看到自己常骑的路上有人比他快,想夺冠 → 自动开始用
- **让品牌和车队入驻**: GCN、各地 club、Rapha 等品牌在 Strava 有官方账号,提升内容密度

**velo 的冷启动**: 不要想"所有骑手都用 velo",而是**先让太原/北京/上海各一个核心圈子用起来**,让城市 KOM 变成本地骑手的社交货币(参考 ADR-007 贡献者众包)。

### 3.5 免费 + 订阅的边界拿捏

Strava 花了 10 年才拿捏好"哪些免费、哪些收费"。今天的边界:

- **免费**: 基础记录 / kudos / feed / 单次 KOM 查看 / club
- **订阅**($80/年): 功率曲线 / 赛段历史对比 / 路线规划 / 训练计划 / 教练建议

这个边界的原则: **社交 (网络效应核心) 永远免费,工具 (个人深度使用) 收费**。

**velo 的边界(v5 初定)**:
- 功率曲线(Strava 收费) → velo **免费**(作为 PR 差异化,见 PRD)
- 赛段历史对比(Strava 收费) → velo **免费**(同上)
- 路线规划(Strava 收费) → velo **不做**(跳转高德,见 ADR-010)
- 训练计划/教练 → velo **v7+ agent 后再考虑**(见 ADR-009)

**velo 的策略**: v1-v4 全免费,用功能吊打 Strava 付费墙。v5+ 商业化时,收费点在 "outcome-based" (训练营 / 精英社群) 而不是 "feature-based" (见 ADR-009 的 agent 规模化杠杆)。

## 四、Strava 做错/没做的 5 件事 — velo 的机会

### 4.1 社交层极浅

Strava 用户自己在论坛上反复吐槽:"Strava clubs 功能弱,除了标记谁和谁骑在一起,club 成员基本没啥可做的";"在 Strava 之外不能发 event,要组队骑车居然比用本地 Facebook 页面还难"。

Strava 的社交停留在:
- Kudos 点赞(低语义)
- Comment 评论(低频使用)
- Club 内 post(需 club owner 有权限)
- Feed 看好友活动(被动)

**没有**:
- 直接匹配"和你骑得像的人"
- 基于共同赛段的社交(赛段页面只是排行榜,不是聚集地)
- 私信 / 约骑 / 线下连接
- 赛段评论 / 照片 UGC 沉淀

**velo 的机会**: Strava 20% 社交 + 80% 工具。velo 反过来做——**80% 社交 + 20% 工具**(见 PRD 主文档)。

### 4.2 约骑/event 生态弱

Event 只能 club owner 创建,这是多年用户痛点。2025-2026 年 Strava 终于开始认真做 event(Activity Event Match + Event Browse,见 §6),但**起步晚了 10 年**。

**velo 的机会**: 从第一天就把"约骑"作为 v5 核心功能之一(PRD 主文档)。

### 4.3 聊天/私信缺失

Strava 至今没有原生私信功能。两个骑手想约下次一起骑,必须通过 Strava 外的渠道(Instagram DM / 短信 / 朋友圈)。

**velo 的机会**: 在微信生态里,私信可以直接跳转到微信聊天(通过小程序分享卡片 → 点击进入好友对话)。**velo 不做私信但借微信私信**,优雅绕开。

### 4.4 对新手极不友好

Strava 对"专业骑手/跑者"非常友好(数据维度深、功能丰富),但对新手:
- 界面信息密度过高
- 术语太多(FTP / NP / TSS / IF)
- 订阅价格 $80/年对新手偏贵

**velo 的机会**: 目标用户虽然是严肃骑手,但**可以在新手引导上做得更柔和**:不强制填 FTP,不首屏展示专业术语,让新骑手也能 3 分钟内理解产品价值。

### 4.5 中国市场战略性放弃

Strava 在中国实际上**完全不能用**:
- 地图偏移(见 §5)
- 微信生态无整合
- 付费订阅对中国用户吸引力低
- 所有高级功能都用美元计价

Strava 从来没认真做过中国市场,未来也做不了(见下一节)。

**velo 的机会**: 直接抢走中国 50-100 万 Strava 用户(很多中国骑手现在痛苦地用国产码表 + Strava 账号混合同步)+ 新增用户。中国市场是 Strava 的完全盲区。

## 五、Strava 永远进不来中国的 4 个结构性死穴

这是 velo **存在的结构性理由**。每一条都不是"Strava 只要努力就能解决",而是**结构性障碍**:

### 5.1 地图合规不可解(测绘法)

中国《测绘法》+ 《关于加强互联网地图管理的若干规定》要求:**所有商用地图必须用 GCJ-02 坐标系**。

Strava 全球统一用 WGS-84 坐标系,数据中心在美国。如果 Strava 想支持中国:
1. 必须在中国境内运营地图服务(牌照)
2. 必须把 WGS-84 坐标实时转 GCJ-02(技术可做但法律和运营成本高)
3. 必须保证用户看到的路径不偏移 500 米(目前偏 500 米是用户诟病核心)

Strava 不太可能为中国市场拿测绘甲级资质(非本土公司拿不到)。**这是完全封死的路**。

### 5.2 数据出境不可解(数据安全法)

《数据安全法》(2021-09 施行) + 《个人信息保护法》(2021-11 施行) + 《数据出境安全评估办法》(2022-09 施行) 三重枷锁要求:
- 用户数据(含 GPS 位置)必须本地化存储
- 出境要通过安全评估
- 数据出境违规最高罚 5000 万人民币

Strava 是美股上市公司,所有数据必须回美国总部。如果要合规运营中国:
- 建立中国独立数据中心(亿级投入)
- 中国数据不能回美国(意味着 Strava 的全球 feed 数据割裂)
- 合规团队 + 运维团队本地化

**投入产出比极差**——中国付费率预计比全球还低(中国用户消费习惯不付"功能订阅"),不值得。

### 5.3 社交图谱不可建(微信生态)

中国骑行社交的**真实载体是微信群 + 朋友圈**,不是 app 内社交。一个典型骑手在:
- 2-3 个本地骑友微信群
- 1-2 个全国训练群 / 品牌群
- 朋友圈分享路线/成绩

Strava **没有微信小程序、没有朋友圈分享、没有微信登录**。它在中国骑手的社交图谱里是**断开**的——你用 Strava 记录,但所有社交发生在别处。

这意味着:即使 Strava 解决了前两个问题,它也无法形成"中国骑行社交平台"的身份,只是"中国骑行记录工具"。而记录工具在中国已经被国产码表(iGPSport / Magene)免费工具替代。

### 5.4 本地信任网络不可进(车店 / 领队 / 赛事)

中国骑行真正的"节点"是:
- **车店老板**: 本地骑行社群的事实组织者
- **club 领队**: 每个城市几个核心骑手主导 200-500 人社群
- **赛事组织方**: 连接车店 + club + 品牌

这些节点是**线下人情关系**,不是 app 功能。Strava 总部在 San Francisco,**根本进不来**。

**velo 的机会**: Tim 本人是太原 club 领队(500 人),天然和本地信任网络有连接。通过 ADR-007 贡献者众包机制,velo 可以与各城市 club 领队建立关系,把线下信任网络直接导入产品。

## 六、Strava 2026-04 Event Browse 更新解读

2026 年 4 月 21 日 Strava 发布了 459.0.1 版本,新增 "活动浏览"(Event Browse) 功能:

> "Event Browse 让你一站式找到本地活动,按地点、运动类型、形式、距离筛选。活动自动填充你周围 20 英里半径内的内容。"

这是 Strava 从 "activity tracker" 向 "event discovery platform" 转型的重要信号。

### 时间线梳理

- 2024-2025: Strava 开始加强 club 和 event 功能
- 2025-07 Activity Event Match 上线(活动自动匹配到参加的 event)
- 2026-03 Club Event Insights 上线(event 后 12 小时给 club admin 发送数据)
- 2026-04 Event Browse 公开上线(按地点 20 英里半径/运动/形式/距离筛选)

### 关键解读: 这对 velo 意味着什么?

**好消息(7 点)**:

1. **市场验证**: 骑行社交的方向是对的。Strava 这种全球头部终于开始认真做,证明 velo 的战略判断不是瞎想。

2. **用户心智教育**: Strava 全球营销预算帮 velo 教育了中国用户"骑行 app 应该有约骑功能"。velo 进入时用户心智已经准备好。

3. **结构限制暴露**: 即使 Strava 做 event,也是 top-down (club → event → RSVP)。velo 可以做 bottom-up(个人 × 地理 × 赛段 → 自发匹配)。两种产品架构,不互相替代。

4. **中国仍然空白**: Strava 的 "20 英里半径"在中国大陆是 0 事件(Strava 在中国无 club),中国骑手用了 Event Browse 什么也看不到。

5. **时间压力变大**: 骑行社交不再是"没人做的蓝海",而是"头部已在做的赛道"。velo 必须在 Strava 或其他玩家(Keep / 咕咚)想起来进中国前,把本土化优势做深。

6. **对标清晰**: velo 可以直接对比 "Strava Event Browse" vs "velo 骑友匹配",讲清差异(Strava 基于 club,velo 基于赛段重合度 + 地理重合)。

7. **融资话术强化**: VC 问"这个方向能不能做",velo 可以答"Strava 10 个月前开始做,验证了方向"。

**坏消息(1 点)**:

- 如果 Keep / 咕咚看到 Strava Event Browse,觉得"我们也该做",velo 面临**国内头部厂**(Keep 有上亿 DAU)的可能竞争。要抢在他们想明白前,把"骑行垂直 + 一线城市"的护城河做深。

### 不变的结论

**Strava 做 event,但 Strava 进不来中国**——四大死穴(§5)没变。Event Browse 在中国大陆仍然空白。velo 的战略位置没有被威胁,反而被**验证**。

## 七、给 velo 的 7 条可执行启示

提炼了 5 项"学 Strava" + 2 项"避开 Strava":

### 要学的 5 条

**启示 1: 社交与数据深度绑定,第一天就做**。
Strava 的成功不是因为 GPS 做得好,是因为 GPS + 社交做得好。velo 不要犯"先工具再社交"的错误——上传 = 分享(默认公开)、活动 = feed 帖、赛段 = 聚集地。

**启示 2: segment 机制抄得更深**。
Strava 的 segment 是"数字排行榜",velo 要做成"赛段社区"——评论、照片、路况、建议、实景。每条赛段变成微型垂直社区。

**启示 3: 硬件中立,永远不绑定**。
velo 当前已支持所有码表 GPX/FIT 导入,要长期保持。不和任何一家码表厂家深度绑定(特别是国产 iGPSport / Magene),否则失去平台中立性。

**启示 4: 冷启动从城市种子开始**。
Strava 早期只在湾区推,velo 早期重点 5 个一线城市(北京 / 上海 / 杭州 / 深圳 / 成都)+ Tim 所在太原。**不要一上来就想覆盖全国**。

**启示 5: 免费 / 订阅边界清晰**。
v1-v6 全免费;v7+ 考虑商业化时,收费点在 **outcome-based 服务**(完赛营 / 精英社群),不在 feature-based 订阅。Strava 的"功能付费墙"在中国市场走不通。

### 要避开的 2 条

**启示 6: 不做实时导航**。
跳转高德完成。Strava 的路线规划 + 导航功能始终在用户吐槽 "不如 Komoot 好",velo 不趟这个坑(见 ADR-010)。

**启示 7: 不一上来就做综合运动**。
Strava 2012 年加跑步是在骑行稳固之后。velo v1-v2 只做公路车,不碰跑步 / 徒步。"focus" 是早期产品最重要的决策,outbase 犯的错(见 outbase 分析)就是太早扩展运动类型。

## 八、投资人 Q&A 里怎么用这份分析

VC 最喜欢问的 Strava 相关问题,标准答法:

### Q: Strava 抄你怎么办?

**标准答法(~2 分钟)**:

"Strava 是 velo 在**国际市场**的 reference product,但**不是**在中国市场的竞争对手。原因是 4 个结构性死穴:

(1) 地图合规——Strava 全球用 WGS-84,中国法律要求 GCJ-02,拿牌照不现实;
(2) 数据出境——《数据安全法》要求本地化,Strava 总部美国不可能搬;
(3) 社交图谱断层——微信生态 Strava 没小程序没朋友圈分享,在中国社交图谱上是隔绝的;
(4) 本地信任网络不可进——中国骑行社群是车店/领队/赛事的线下关系,Strava 的 San Francisco 团队进不来。

竞争不是 velo vs Strava,是'全球通用产品 vs 本土垂直产品'的永恒命题——和 Uber vs 滴滴、Airbnb vs 小猪短租、Spotify vs QQ 音乐同类。

Strava 每次更新对 velo 都是利好——他们替 velo 教育中国市场,而中国市场他们进不来。"

### Q: 你和 Strava 有什么差异?

**标准答法(~1 分钟)**:

"Strava 是 80% 工具 + 20% 社交的产品,velo 做的是 80% 社交 + 20% 工具。

具体上,Strava 的 club 和 event 是 top-down(俱乐部 → 活动 → 报名),velo 是 bottom-up(个人 × 地理 × 赛段重合度 → 自发匹配)。

此外,velo 直接把 Strava 的付费墙功能(功率曲线 / 赛段对比)免费开放,用 PR 语言就是 '对标 Strava 付费功能全部免费'——这个锚点在中国市场对严肃骑手极有杀伤力。"

### Q: 那 Strava 2026 年 4 月刚上线 Event Browse,抢先你了吗?

**标准答法(~30 秒)**:

"Event Browse 验证了 velo 的战略方向正确——如果 Strava 都开始往约骑移动,说明方向是对的。

但 Strava 的 Event Browse 在中国大陆是 0 事件显示的(因为中国没有 Strava club)。所以这是它 '替 velo 教育市场',不是 '抢先 velo'。

velo 还有 12-18 个月的时间窗口,在 Strava 或国内巨头真正进入这个赛道前,把中国一线城市骑行垂直的密度做起来。"
