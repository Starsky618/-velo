# 行者 / 黑鸟 / 骑记 — 中国骑行 app 前辈的失败模式

> **这份文档给谁看**: Tim 本人长期内参 + 核心合伙人看"踩过的坑"。不适合给 VC 看(太阴暗),但自己要反复读。
>
> **一句话核心论点**: **中国骑行 app 前辈们都没死,但都没活好。他们的共同问题不是技术不行,而是走错了战略方向**:
> (1) 行者:综合化扩张 + 硬件/电商变现 = 定位模糊
> (2) 黑鸟:聚焦社交但后劲不足 = 没吃到红利
> (3) 骑记:转硬件 + 共享单车 + 电助力 = 骑行 app 业务彻底边缘化
>
> velo 要在这份"前人坟墓地图"上走出新路——看着他们的错误,避开他们的坑。

## 一、中国骑行 app 的"坟墓地图"

从 2012-2016 年"骑行 app 创业潮"时期活下来的玩家:

| 名称 | 创立时间 | 2026 现状 | 核心问题 |
|---|---|---|---|
| **行者** | 2012 | **仍活跃**(3500 万注册 / 累计 50 亿公里) | 扩张到综合运动 + 硬件 + 电商,定位模糊,核心用户流失 |
| **黑鸟单车** | 2014 | **还在更新,但沉寂**(几百万用户) | 聚焦社交但后劲不足,2016-2017 是巅峰 |
| **骑记** | 2012 | **被边缘化**(母公司转做电助力折叠车 + 米家生态) | 进入小米生态链后 app 业务已非主业 |
| **野兽骑行** | 2013 | **转型消亡**(2016 进共享单车,随后倒闭潮) | 硬件起家但共享单车泡沫破灭后重创 |
| **益动 GPS** | 早期 | **已下架** | 更早期的工具类 app,无差异化 |
| **兔子骑行** | 2014-2015 | **已废弃** | 同上 |
| **破风骑行** | 早期 | **已消失** | 同上 |
| **骑遇** | 2014-2015 | **低活跃** | 社交尝试未成规模 |
| **野途** | 2015 | **已转型** | 综合户外媒体为主 |

**活下来的只有行者 + 黑鸟 + 骑记**,且三家都在不同程度"被边缘化"或"走偏路"。

### 过去 10 年的核心问题

创业潮结束后,骑行 app **没有一个真正做出"骑行社交"核心价值**。要么变成"轨迹记录工具"(低粘性)、要么变成"硬件导流平台"(商业模式不成立)、要么转型离开骑行(如野兽转共享单车、骑记转电助力)。

velo 要在这个"骸骨遍地"的战场上重新尝试,**必须不重蹈覆辙**。

## 二、行者:国内最大,但战略迷失

### 2.1 规模与发展轨迹

| 里程碑 | 时间 | 说明 |
|---|---|---|
| 创立 | 2012-10 | 原团队独立开发 |
| 用户 100 万 | 2014-09 | 首轮爆发 |
| 被上海大不自多信息科技收购 | 2015-01 | 新团队主导(CEO 蒋旻宸) |
| 发布行者蓝牙踏频码表 | 2015-11 | 硬件首次试水 |
| 累计 10 亿公里 | 2018-02 | |
| 注册用户 2000 万 | 2022-06 | |
| **2025 年注册用户 3500 万 / 累计 50 亿公里** | **2025-12** | **当前规模** |
| 最新版本 3.26.x(含热力图) | 2026-01 | 产品仍在迭代 |

注: 3500 万是注册不是 MAU。实际 MAU 远低于此,业界估计 200-500 万(5-15%)。

### 2.2 商业模式

- **行者 PRO 订阅**: 解锁爬坡分析、估算功率、生涯纪录、运动热图、轨迹合并、3D 轨迹等"Strava 式付费墙"
- **行者商城**: 运动装备电商
- **赛事报名服务**: 一站式报名骑行 / 跑步 / 越野跑比赛
- **运动保险**: 增值服务
- **硬件产品**: 行者峰码表 + 其他外设

### 2.3 行者做对的

1. **品牌语言好**: "虽千万里,吾往矣" slogan 到今天都是骑行圈可识别的。行者这个名字带归属感
2. **活下来了**: 2012-2026 连续 14 年存活,在中国互联网"90% 初创在 3 年内死"的背景下是少数派
3. **全国覆盖**: 605 城市覆盖,数万个俱乐部
4. **SaaS 扩展有思路**: 2018 年推出车店系统、俱乐部系统、赛事系统三个 SaaS,这是对的方向,只是执行不足

### 2.4 行者做错的 — velo 要警惕

**错误 1: 综合运动扩张失焦**

行者从 2014-2015 开始扩展到跑步 + 徒步 + 越野跑 + 登山等。**这让行者变成"综合户外运动平台"**,稀释了"骑行"的专业心智。

用户对行者的评价变成:"做什么都不专精"。骑手吐槽:"跑步我用咕咚,骑行我用行者,但行者的骑行功能好像不如咕咚专业"。

→ **velo 教训**: **死扣公路车垂直,v1-v6 不碰跑步、徒步、综合运动**。见 ADR-007。

**错误 2: 硬件 + 电商 + 软件三驾马车**

行者从 2015 年的"基本概念"开始,希望通过"软件圈用户 + 卖硬件 + 开电商"实现商业闭环。但这个战略被行业现实打败:

- **硬件做不过专业品牌**: iGPSport / Bryton / Garmin 已经在码表市场占主导。行者峰码表知名度低,份额小
- **电商做不过综合平台**: 京东/天猫/淘宝的骑行装备已经很丰富,用户用行者商城理由不强
- **软件被前两项拖累**: 用户打开 app 发现到处是商城入口 / 硬件广告,**专业骑手反感**

→ **velo 教训**: **不做硬件,不做装备电商**(v5+ 至少)。velo 保持"纯软件 + 垂直社交"身份,和所有硬件厂家保持中立关系。

**错误 3: 订阅模式中国化水土不服**

行者 PRO 推出后,中国用户反响平平。原因:
- 中国用户心智上**不愿为"功能"付订阅**(对比美国愿意为 Strava 付 $80/年)
- 解锁的功能(爬坡分析/估算功率)中国国产码表已经免费提供
- 订阅无社交奖励,付了也没面子

→ **velo 教训**: **v1-v4 全免费**。v5+ 商业化走 **outcome-based**(训练营/精英社群/装备联运),不是 feature 订阅。见 ADR-009 + PRD。

**错误 4: 社交深度不够**

行者有俱乐部、动态、勋章、积分,但**没有真正的身份图谱**。点开某个用户的主页,看到的是:
- 总里程 / 骑了几年 / 得了几个勋章
- 不是"他常骑哪 4 条赛段 / 他对这些赛段的笔记 / 他骑得像谁"

这让用户的"社交货币"变成"我骑了 1 万公里"(数字,任何人都能达到),**不是"我是这段路的 KOM + 深度贡献者"**(身份,有辨识度)。

→ **velo 教训**: velo 学 Letterboxd + Strava 混血,**身份 = 你和赛段 + 路线的关系**,不是总里程数字。

## 三、黑鸟单车:社交聚焦的早期探索者,增长停滞

### 3.1 规模与轨迹

- **创立**: 2014 年(Beijing Bamboo Networks)
- **2015-2016 巅峰**: 全国 5 万个俱乐部 + 300 万用户(当年"36 氪推荐")
- **2025 最新数据**: 数万个俱乐部 + "数百万用户"(官方模糊表述,实际增长几乎停滞)
- **产品定位**: 以骑行俱乐部为核心的社区服务平台,"解决怎么骑、跟谁骑、去哪骑"
- **商业模式**: 一直尝试服务收费(定制骑行服 + 赛事报名),**收效甚微**

### 3.2 黑鸟做对的

1. **方向对**: 比行者更早聚焦"骑行社交"而非"综合运动工具"。从第一天起就把"俱乐部"作为核心组织单元
2. **节奏稳**: 没有盲目扩张硬件/电商,持续做 SaaS 型服务。没摔大跟头
3. **真实性高**: 创始人魏涛是行业内人士,带着"骑友做骑友产品"的诚意

### 3.3 黑鸟做错的 — velo 要吸取

**错误 1: 运营跟不上产品**

黑鸟 "界面还比较简陋,交互和视觉都有待提高"(知乎用户 2013 年评价)——这个评价到 2020 年后仍然类似。产品功能对了,但**执行力和美学跟不上**。

这让产品在 2014-2018 年的"颜值党"时代输给了行者(行者视觉更精致 + 动画更顺滑 + 商业运营更激进)。

→ **velo 教训**: **产品细节 / 视觉设计 / 交互流畅性** 是竞争壁垒之一,不是附加价值。velo 必须在这个维度上达到 iOS 一线 app 水准(见前端设计原则)。

**错误 2: 变现试错太慢**

黑鸟**太克制了**: 不做电商、不做硬件、不激进付费。结果是**没有资金继续投入产品**,技术债和体验问题累积。

到 2020 年后,黑鸟的增长速度被行者和新兴平台(如 Keep 骑行板块)甩开。

→ **velo 教训**: velo 前期可以免费,但**心里要明确商业化的路径图**(见 PRD v5+ 商业化章节)。**不能无限免费**,否则 3-5 年后耗尽初始资金。

**错误 3: 没有出圈节点**

黑鸟 10 年做的是"骑行圈内人用的 app",没有形成"每个骑手都必用"的心智。行者因为是第一名(有名字卡位 + 大 marketing 投入)成为骑手入门默认 app。

这是典型的 **"第二名陷阱"** — 第二名的份额永远不足 20%,长期活在第一名阴影下。

→ **velo 教训**: **不能甘当第二名**。velo 必须在"骑行社交"这个**新品类**上做到第一,不是在"骑行工具"上做第二。

## 四、骑记:被小米生态链"吞并"的骑行 app

### 4.1 规模与轨迹

- **创立**: 2012 年厦门(前身美塔思科技)
- **骑记 app**: 2014 年推出,约 100 万用户(2016 年)
- **2014-09 加入小米生态链** — 这是**关键转折**
- **2017+**: 母公司转做硬件(QiCYCLE R1 公路车 / 米家骑记电助力折叠车 / 米家充气宝 / EUNi 电动滑板车)
- **2021 总部迁深圳**,聚焦电助力产品
- **2026 现状**: 骑记 app 虽然还在但**边缘化**,核心业务是硬件

### 4.2 骑记的故事 — 一个骑行 app **被融资条件改变命运**的案例

骑记创始人黄尉祥是真心想做骑行的人。但加入小米生态链(2014)后:

- **小米要的是硬件生态**,不是纯软件
- **小米文化是"性价比硬件刷爆款"**,软件/社区不是主业
- **骑记的资源开始向硬件倾斜**: R1 公路车 / 电助力 / 儿童车 / 共享单车"小白单车"(2016 后泡沫破灭)
- **App 部分进入"维护状态"**(6.0 版本迭代缓慢,没有核心创新)

"骑记说"2015 年的运营专访(知乎)是凄凉的:创始人自己说"累积非常慢,第 1 个用户到第 100 个用户花了 1 星期,到 1000 个用户花了 2 个月"。后来被小米生态链"救了",但也失去了做成"中国骑行 Letterboxd"的机会。

### 4.3 骑记给 velo 的教训

**教训 1: 融资要选对齐的股东**

骑记拿小米的钱,被拉去做硬件;野兽骑行拿真格/李开复的钱,被拉去做共享单车;行者拿湖杉/银杏谷的钱,被拉去做综合化扩张。

**拿的钱决定做的事**。

→ **velo 教训**: 如果 velo 融资,**只找理解"垂直社交慢火煨肉"**的投资方。拒绝:
- 想要快速退出的 VC
- 逼你做硬件的战略投资
- 逼你扩到综合运动的基金
- 想要你做共享出行的基金

优选对齐的投资方类型:
- 个人天使(特别是骑行圈内 + 理解 Letterboxd 模式的人)
- 长期耐心资本(类似 Tiny 对 Letterboxd)
- 骑行品牌战略投资(如某高端车架品牌)

**教训 2: 小团队做垂直也要 hold 住节奏**

骑记早期只有黄尉祥和几个合伙人,累积用户到 100 万后被小米看中。**如果当初能 hold 住 3-4 年做深社交,可能今天就是中国 Letterboxd**。

→ **velo 教训**: 前 3-4 年 velo 不追求估值/增长速度,而是**做深垂直社交密度**。哪怕只有 5 万活跃用户,比起 500 万"工具型用户"(不社交、不付费、不留存)价值高 10 倍。

## 五、野兽骑行 / 益动 GPS / 兔子骑行 / 破风 — 其他死掉的同行

### 5.1 野兽骑行:2015-2016 最热,后转共享单车倒闭

2015 年融过数百万美金天使(真格徐小平)+ 5000 万 A 轮(李开复)+ 3000 万 A+ 轮(新动金鼎)+ 1.5 亿 B 轮(2016 共享单车赛道)。**是同期最热的骑行创业**。

**死法**: 2016 年转共享单车赛道,参与小白单车。共享单车泡沫破灭后重创,核心团队流失,野兽骑行 app **几乎无人更新**。

**教训**: 千万**不要被风口拉走**。2016 共享单车热,野兽一脚踩进去,结果泡沫破灭全完。velo 要警惕"AI 热"的风口诱惑——ADR-009 的 agent 独立原则就是防御这件事。

### 5.2 益动 GPS / 兔子骑行 / 破风骑行:工具类同质化死亡

这几个 app 2013-2015 年都是"骑行轨迹记录工具",功能和行者/黑鸟高度同质化,**没有差异化定位**。

结局:
- 用户规模上不了百万
- 没有融资
- 作者失去兴趣或转型
- 2018-2020 年陆续下架或停更

**教训**: **工具类 app 没有差异化就是死路**。velo 必须从第一天起就不是"另一个骑行记录工具",而是"骑行身份图谱 + 社交网络"。

### 5.3 骑遇 / 野途 / 破风:社交尝试未成规模

这几个尝试了社交方向,但要么功能单薄、要么运营乏力、要么时机不对。**都没有成为骑行社交的"大众品牌"**。

**教训**: 社交产品做对一次就够了(Letterboxd / 小红书 / Strava),做错很多次也白搭。velo 的社交机制必须**从第一天就精心设计**(见 Letterboxd 对标 + PRD)。

## 六、5 个共同的失败模式 — velo 要明确避开的雷

### 雷 1: 综合运动扩张病

**症状**: 骑行 app 做着做着加跑步、徒步、登山、游泳、爬山、铁三…
**诱因**: "单品类用户天花板低,扩到综合运动天花板更高"
**现实**: 稀释了专业心智,每个品类都做不过垂直竞争者
**患者**: 行者(已感染)、outbase(已感染,见 outbase 分析)、野途(最终转综合户外媒体)

**velo 防御**:
- ADR-007 明确 "不用算法自动生成赛段,用贡献者众包"(防止技术投入诱导扩张)
- PRD v1-v6 明确只做公路车
- 任何"为什么不加跑步?"的提议都回答"velo 做骑行身份图谱,不是运动综合 app"

### 雷 2: 硬件 + 软件 + 电商三线作战

**症状**: "做 app 圈用户 → 卖硬件赚钱 → 开商城做增值"
**诱因**: 看 Strava + Garmin / Fitbit 的模式以为能复制
**现实**: 每条线都需要独立团队 + 独立资本 + 独立渠道。3 人学生团队绝对做不动
**患者**: 行者(码表 + 商城 + 赛事)、野兽(码表 + 整车 + 共享单车)、骑记(折叠车 + 电助力 + 配件)

**velo 防御**:
- ADR-006 只做小程序不做 app(v7+)
- 明确不做硬件(v10+)
- 不做装备电商(v8+,只做内容导购不做库存)

### 雷 3: 功能订阅中国化水土不服

**症状**: 推出 Pro 订阅解锁功率曲线 / 赛段对比 / 高级统计 → 用户不付
**诱因**: Strava 订阅模式(美国有效)直接搬中国
**现实**: 中国用户不习惯为"功能"订阅,国产码表已经免费提供
**患者**: 行者 PRO(成果平平)、咕咚训练营(订阅成效差)

**velo 防御**:
- v1-v6 全免费。**用免费吊打 Strava 付费墙**(功率曲线/赛段对比/训练负荷免费做)
- v5+ 商业化走 **outcome-based**: 训练营/完赛营/精英社群/装备联运
- 不走 feature-based subscription

### 雷 4: 拿错钱被拉偏

**症状**: 拿了 VC 的钱开始做 VC 想要的事(硬件/共享出行/综合化)
**诱因**: 早期融资诱惑,接不接很难
**现实**: 融资方向错了比没融资还惨——被拉去做不擅长的事,核心团队流失
**患者**: 骑记(被小米拉去做硬件)、野兽(被李开复拉去做共享单车)

**velo 防御**:
- 前 3-4 年**不融 VC**,或**只融对齐天使**(理解 Letterboxd 模式的个人天使)
- 融资前先明确:这笔钱让 velo 做什么是对的?如果答案是"扩到综合运动 / 做硬件 / 上市",直接拒绝
- 参考 Letterboxd 2023 被 Tiny 收购作为退出路径,**不是 Sequoia 式 IPO 路径**

### 雷 5: 产品细节不够精

**症状**: 功能做了但体验粗糙,图标难看,动画卡顿,交互反人类
**诱因**: 创业团队优先 feature 交付,忽视细节打磨
**现实**: 第一名总是细节最好的,第二名可能功能 over 第一名但体验输
**患者**: 黑鸟(长期被吐槽视觉简陋)、骑记(UI 老旧)、益动 GPS(已死)

**velo 防御**:
- 前端设计质量对标 iOS 一线 app(Apple Fitness/Strava/Letterboxd 水准)
- v5 spec 加"UI/UX 标准体检"任务
- 每期 Demo 时 Tim 亲自骑行使用,发现卡顿/丑陋/反人类立即 flag

## 七、中国骑行市场的结构性信号 — velo 能看到的机会

前辈失败的同时,中国骑行市场本身在增长。核心信号:

### 信号 1: 公路车正在中国崛起(2024-2026)

2017 年前中国骑行以山地车为主(山地:公路 = 8:2)。2024-2026 **公路车正在快速增长**:

- 京东 2024 五一数据: 公路自行车销售额同比 **+200%**
- 上海/北京/杭州街头公路车数量肉眼可见飙升
- 高端公路车品牌(闪电/崔克/Factor/Wilier)在中国销售暴涨
- 公路车骑手画像与 velo 目标用户 100% 重合(严肃/一线城市/年轻/高消费)

**这是 velo 的天时**——对标 Strava 2009 年美国起步时的公路车浪潮。

### 信号 2: 国产码表崛起(iGPSport / Magene / Bryton)

中国骑手越来越多用国产码表:
- **iGPSport** 已成为中国本土中端码表市场头部
- **Magene** 在功率计 + 踏频器领域有存在感
- **Bryton** 台湾品牌,中国市场占比提升

**关键**: 这些国产码表都支持 Strava 同步,但**中国用户用不了 Strava**(地图偏移 / 订阅 / 无微信生态)。

**2026-05 时间窗口**: 行业内信号显示国产码表可能因合规原因失去 Strava 同步能力。这个窗口 velo 必须抓住——成为"码表同步的默认选择"(骑记错过了这个机会因为转做硬件了)。

### 信号 3: 微信骑行群数量爆发

2023-2026 年中国一线城市的骑行微信群数量**几何增长**。一个严肃骑手平均在 2-3 个本地骑友群 + 1-2 个全国训练群 + 装备群 + 赛事群。

微信群是中国骑行社交的**真实载体**,但微信群本身有极大缺陷:
- 信息爆炸,重要信息被淹没
- 没有结构化(无排行榜 / 无赛段 / 无历史)
- 陌生人加好友摩擦高
- 人数上限(500)

**这正是 velo 的切入点**: **把微信群里不可结构化的社交,搬到 velo 结构化**。骑友先在微信群认识(熟人),然后在 velo 建立深度身份图谱(赛段 + 路线 + 成就)。velo 和微信群共生,不替代。

### 信号 4: 骑行赛事越来越多

全国每年数千个骑行赛事(从大型专业赛到城市周末挑战)。中国骑手报名这些赛事的渠道分散,**velo 长期可以成为"骑行赛事 + 训练 + 社交一站"的聚合平台**。

## 八、velo 的反向定位 — 学前人的教训做出的 5 个反向决策

把上面的雷区和机会综合,velo 应该是行者 / 黑鸟 / 骑记 的**反面**:

### 反向 1: 垂直死守公路车 vs 综合运动扩张

- 他们: 扩到跑步/徒步/综合
- velo: 只做公路车(v1-v6)

### 反向 2: 不做硬件/电商 vs 软件 + 硬件 + 电商

- 他们: 软硬件 + 商城三驾马车
- velo: 纯软件 + 垂直社交,硬件保持中立不做

### 反向 3: 社交密度 vs 用户数量

- 他们: 3500 万注册用户但社交深度浅
- velo: 5 万活跃用户但每人有深度身份图谱

### 反向 4: outcome-based 商业化 vs feature 订阅

- 他们: Pro 订阅解锁功能
- velo: v1-v6 免费,v5+ 训练营/精英社群 outcome 收费

### 反向 5: 对齐股东 vs 随便融资

- 他们: 拿了 VC 被拉去做硬件/综合/共享单车
- velo: 前 3-4 年不融 VC 或只融对齐天使,避开被拉偏的风险
