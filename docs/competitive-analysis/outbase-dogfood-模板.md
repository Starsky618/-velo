## 一、为什么需要你亲自 dogfood

**我 Claude 做不了的事**:
- 下载 iOS app(没权限)
- 注册账号、骑车上传、用 7 天后评价
- 感受产品的"气味"(interaction texture / 视觉 polish / 社区氛围)
- 判断"用户真实在用"的感觉 vs "僵尸 app"的感觉

**只有你能做的事**:
- 在真实骑行中使用 outbase(不是看 app 截图)
- 联系 outbase 的活跃用户观察社群活跃度
- 判断 outbase 的赛段/挑战是否真的有人在竞争
- 评估 outbase 的 UX 细节和工程质量

**重要性**:
- outbase 是 velo **最直接的中国骑行社交竞品**——如果 outbase 已经把我们想做的事做到 80%,velo 战略必须调整
- 如果 outbase 还只是"demo 级别"(pre-PMF 苦撑),velo 可以更有信心快速切入
- **猜测不可靠**,必须基于真实数据决策

## 二、outbase 公开信息快照(我能查到的)

### 基本信息

- **运营公司**: zeusfit(上海,tantanapp 账户名关联 "探探" 母公司的可能性待验证)
- **iOS App ID**: 6739030517
- **Android**: 通过应用宝分发(`com.tantanapp.outbase`)
- **上架时间**: 2024 年下半年左右(Apple App Store 版本迭代显示)
- **主推市场**: 中国大陆(应用文案全中文,未见海外版本)

### 产品自我定位(官方 app store 文案)

引用: "用运动连接世界,让每一次出发都成为社交冒险"

核心宣称功能:
1. **运动社交**: 动态广场 / 点赞评论 / 约练
2. **实时挑战热力榜**: 城市地标路线 / 附近俱乐部活动
3. **专属俱乐部**: 创建社群 / 团队成就 / 挑战 / 云端相册
4. **实时运动数据**: 连接智能设备 / 自动生成轨迹

### 关键信号(从 app store 迭代笔记读出)

2026 年最新更新包括:
- "记录功能上线" — **他们之前没有自己的记录功能**?
- "运动类型扩展" — 从骑行扩展到**跑步、游泳、步行、普拉提、体能训练**
- "批量上传数据" — PC 端 Outbase.cn 可批量上传历史数据
- "首页地图焕新" — 好友/俱乐部成员轨迹一览
- "动态卡片" — 发现附近人的运动灵感
- "新增私聊功能" — **之前没有私信**?

### 信号解读(我的初步判断)

几个观察 → 初步假设:

1. **"记录功能上线" 是最近的事**: 说明之前 outbase 是"社交 + 别处记录(Strava/行者)"的混合模式,最近才自己做了记录。这说明**产品还在 pre-PMF 状态**,核心功能(记录)刚上线。

2. **运动类型扩张到 6+ 种**: 骑行 + 跑步 + 游泳 + 步行 + 普拉提 + 体能训练。这是典型的 **综合化扩张病**(见行者失败模式),说明**创始团队没有守住骑行垂直**。

3. **最近才加"私聊"和"动态卡片"**: 说明社交机制还在基础搭建阶段,不是成熟的社交网络。

4. **tantanapp 关联**: 如果真和探探(陌生人社交 app)有关联,意味着团队有社交产品经验但不懂骑行。这是**反向的劣势**(骑行需要懂骑手)。

这些都是**假设**,需要你 dogfood 来验证。

## 三、Dogfood 执行计划(2 周日程)

### Week 1(4-22 至 4-28): 使用 outbase 作为你的主要骑行 app

**目标**: 像一个新用户一样真实体验 outbase

**每日动作**:
- 骑车一次,用 outbase 记录(或上传)
- 连接你的码表(iGPSport/其他)到 outbase
- 浏览动态 / 点赞他人 / 评论他人
- 加入 1-2 个俱乐部
- 挑战 1-2 个赛段 / 路线
- 主动发 1-2 条动态

**每日记录**: 5-10 分钟,在这份文档对应 week 1 checklist 填观察

### Week 2(4-29 至 5-5): 观察 + 对比分析

**目标**: 切换回 velo 视角,做对比

**每日动作**:
- 不再主动使用 outbase,但继续观察(看通知、看动态)
- 仔细观察 outbase 的**运营行为**(推送、官方活动、赛段扩展节奏)
- 联系 1-2 个可能在用 outbase 的骑友(你 500 人骑行群应该有)
- 观察 outbase 的用户画像和讨论内容

**每日记录**: 5-10 分钟,在这份文档对应 week 2 checklist 填观察

### Week 3(5-6 开始): 做决策

基于 2 周观察,回到本文档第 6 章填"velo 相对 outbase 的差异",决定是否调整 velo 战略。

## 七、结论模板:三种可能的发现 + 相应对策

根据 dogfood 结果,outbase 会落在三种状态之一。每种状态对应 velo 的不同对策:

### 状态 A: outbase 是"pre-PMF 苦撑"(概率预估 50%)

**迹象**:
- 日活寥寥(动态广场每天十几条)
- 最近版本才上线"记录功能"(核心还没做好)
- 社区氛围冷清,发动态无人点赞
- 扩张到 6+ 种运动是**pre-PMF 慌乱信号**
- 工程质量一般,bug 多

**velo 对策**:
- **加速当前战略**,2026 年 Q3 前全力冲"公路车垂直",不分心 outbase
- outbase 对 velo 不构成威胁,反而是"提前验证方向" 的友军
- VC 问的时候就说: "outbase 是我们的正面竞争,但他们已经扩到 6 种运动,pre-PMF 苦撑,velo 死守公路车垂直,结构性不同。"

### 状态 B: outbase 在"成长但尚未爆发"(概率预估 35%)

**迹象**:
- 日活若干千到一万,在缓慢增长
- 核心产品(记录+赛段+社交)基本能用
- 社区有一定活跃度但非主流骑行 app
- 运营节奏正常,运动类型扩张是战略选择不是慌乱

**velo 对策**:
- **加强垂直深度**,特别是 velo 独有的"赛段 UGC / 身份图谱 / 微信生态整合"
- 紧密跟踪 outbase 动态,每 2-3 个月重新 dogfood 一次
- PRD 明确写"velo 的三个差异化:微信、本地信任、垂直深度"作为与 outbase 的护城河

### 状态 C: outbase 在"真实起飞"(概率预估 15%)

**迹象**:
- 日活过万并在增长
- 核心用户群出现
- 社交氛围已经形成(陌生人被关注有质量互动)
- 产品体验专业,工程质量高
- 小红书/骑行群正面讨论增加

**velo 对策**:
- **战略重新评估**:velo 的竞争面会硬得多,需要明确差异化 + 加速
