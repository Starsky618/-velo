# 西山南部怎么骑：区域选择网络 v1

日期：2026-08-14
状态：research shadow；11 条选择通过硬门，1 条太古路异常折返被淘汰；5 个 MountainModule 资源仍等生产只读 GLO profile 导出

## 先说结论

这片区域不是一条“天龙山路线”，而是 **5 种目的地骑法 + 1 条太古路长范围过境边界**：牛家口南线、天龙山东侧主爬、天龙山北侧 / 龙山店头、石碑—西门起伏、店头—蒙山。太古路 o85/o49 只证明一个更长的南部接入范围，本轮不把它硬说成第 6 个目的地。

**主流轴是天龙山东侧。** 完整主轴 o17 本身为 708 人 / 3899 次 / 181 星；嵌套在它里面的 o18、o57、o87、o96 分别达到 954/6489、883/4917、833/4395、959/6427。它们是同一条东侧主爬上的岔口段、回旋桥、最后一公里和两圈圈，作用是给局部区间加方向热度，不是五条额外路线，也不重复累计距离和爬升。

北侧不是东侧的别名。o8 是龙山 / 店头方向的另一条完整 approach，o21 以反向下降证据嵌套，o50/o93/o98 是局部爬段。牛家口也是独立南线，o55 是局部正向证据，o89 是反向局部，o97 只覆盖共享上部；这些都不足以把牛家口、东侧和北侧强并成一条物理路。

石碑—西门只保存 o78 一份 canonical 几何：向西门骑时反转 traversal、交换进出口和爬降，o79 只贡献反向热度。店头—蒙山 o9 则是独立完整目的地轴。
