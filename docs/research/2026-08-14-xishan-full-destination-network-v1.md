# 西山剩余目的地与南北主脊批处理 v1

## 先说人话：西山现在可以分成五种骑法

第一种是**单坡目的地**：启春阁、奥申、狼坡、偏桥沟、经典杜关、枣杜、玉泉、柴化、一线天、二库阁楼、庙前山候选。它们适合“今天就想吃这一条坡或看这一个地方”，不需要为了显得完整，硬塞进一条百公里大线。

第二种是**南半连续爬**：天龙山群出来，经万亩/奥申，再接狼坡，最后从杜儿坪或桃花沟方向退出。当前奥申—狼坡 10.890 公里双坡已经硬重放；天龙山西门到万亩、狼坡到退出点仍缺自然端口。

第三种是**杜关选择区**：经典杜关、偏桥沟、新杜关旅游公路不是一个名字的三种写法。经典杜关是 9.286 公里/+551.2 米的杜儿坪—太古路主轴；偏桥沟是 4.340 公里/+305.8 米的支沟；新杜关已用 exact o117 和 production GLO fact 89 闭合为 15.023 公里/+296.8/-13.3 米的完整 3D 道路轴，但全轴没有达到 ClimbPro v1 的连续爬坡门槛。它是长缓升、带起伏的旅游公路走廊，不是一条可以硬贴 Cat 的“整坡”。

第四种是**北半连续山路**：桃花沟/化客头—S104/柴化—玉泉—马头水—横岭/崛围—汾河二库。这里的单路事实很完整，但桃花沟到玉泉、马头水到横岭/二库的短连接还没有全部冻结，所以现在能讲每条路，不能报一条伪精确“北半环”总公里数。

第五种才是**环西山大长线**：南到北主脊、北到南反爬、南半、北半，以及再加汾河/城市返回线的真正闭环。官方宣传的西线顺序本身很清楚：晋祠—牛家口—天龙山—蒙山—凤颐谷—田家沟—狼坡—桃花沟—玉泉—马头水—崛围山—汾河二库；2024 赛事西赛段则给出了天龙山路—旅游公路西段—太古路—杜关线—S104—柴化路—玉兰路—玉泉山的另一条可执行骨架。[山西文旅线路](https://www.jcgov.gov.cn/dtxx/zxts/202410/t20241017_2049628.shtml) [2024 环太原赛段](https://www.sx.news.cn/20241029/905056efee2a4bd98763517b4fd3aad4/c.html)

所以主流路线不是“狼坡一条”或“杜关一条”，而是**西山旅游公路南北主脊**；狼坡、桃花沟、杜关、玉泉、横岭等是嵌在主脊上的目的地或分支。国家级户外运动目的地名单也把太原方向概括为“环西山—汾河 骑行+”，但这仍是目的地概念，不是一份自带精确 GPX 的路线事实。[国家发展改革委名单](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202510/P020251024741903247891.pdf)

## 局部热门段怎样嵌在整条路里

- **奥申**：o27 是 5.225 公里完整主轴；o103 是反向局部。o7 名为“奥申反爬”，但几何与 o27 主轴 disjoint，它实际更适合作为奥申上端—狼坡底连接路的方向热度证据，不能当作第二条奥申全线。
- **狼坡**：o38/o42 是同一物理轴正反；o95 是前段，o52 是邀月阁局部。四条热度被投影进同一条 3.415 公里轴，不相加成 10 公里。
- **桃花沟**：o22 是 6.363 公里完整主轴；o44/o46 是反向局部，o47/o70/o81/o92 是观景台、北门和陡坡区间。它们解释“哪里更热”，不是路线 waypoint。
- **经典杜关**：o23 是完整轴；o60/o72/o94 是最陡坡、上段和铁门后区间；跨杜关/偏桥的 o71 只保留为 composite evidence，不建立第三条重复道路。
- **枣杜**：o116 是本次 exact 补录的完整 Strava 轴，旧 active-81 的 o65/o66 只保留为局部见证。完整轴只存一次，正向重放为 Cat 2 长持续坡，反向重放为下降，不把局部热度重复累加成第二条整坡。
- **新杜关**：o117 是新旅游公路到岔口的独立完整轴；它与经典杜关 o23 物理分离、证据分离、ClimbPro 结论也分离。它有完整 3D 海拔，不代表一定会检测出一条分级坡。
- **偏桥沟**：o13/o31 是同轴正反。raw oracle 因自相交给出 indeterminate，但 canonical 投影得到完整正反覆盖，所以可以成族，仍不等于已验证道路通行状态。
- **玉泉山**：南侧主爬 o15 与石膏厂入口 o88 有共享上段，但下端入口不同，必须保存成两个物理选择；o41 南下和 o101 北侧也不能硬合并。
- **二库**：阁楼—马头水 o40 是景观起伏；o114/o102 是另一条西侧盘山正反候选；o82 是马头水—横岭连接。三者相邻，但不是一条赛段。

## 单独目的地怎样理解

### 启春阁（万亩）

这是离城市更近的单独爬坡目的地，不应被“奥申”吞掉。Tim 的照片和专门介绍继续保留；旧 4.17 公里、legacy +263 米 GPX 已退出产品数据源。它适合短时单点骑、看城市和盘山路，但当前还没有 active observation/GLO 绑定，所以不能生成整坡 ClimbPro，也不能借奥申 o27 替换。奥申 o27 的下端在万亩侧，只是奥申主轴入口关系，不等于启春阁路线本身。

### 汾河二库阁楼

它不是“横岭前的一个路标”，而是可以单独去的景点走廊。o40 从阁楼到马头水 5.653 公里，只有 +119.2/-57.0 米，更像山中起伏和观景串联。适合不想把一天都变成持续主爬、但愿意承担二库外接驳的人。代价是到横岭还没有一个经过 provider 闭合的短端口。

### 王封一线天

核心是沟底—景区石碑 2.598 公里/+167.5 米。适合专门看峡谷/沟谷目的地，不必强行套进西山主脊。o39 到豆腐店更长，但 raw 几何关系 mixed；o32 是大窊村引道。现阶段最诚实的做法是先讲 o19 核心，再把引道作为待组装连接。

### 庙前山（228 台）

庙前山和 228 台可以作为一次单独的屋脊目的地骑行，但当前还没有一条已证实抵达 228 台的 VELO 路线。active-81 里最强的道路候选是 o73“3.5 km 1812 top”：3.648 公里、GLO +212.5 米，191 名骑手、471 次记录、10 次收藏。它的终点接近公开资料描述的庙前山山脊位置，仓库也有 Tim 拍摄的 228 台和俯瞰太原照片；但 source 名称没有写“庙前山/228 台”，所以当前结论只是**很强的身份候选，不是已经闭合的 landmark binding**。把 o73 当庙前山路线使用前，还必须确认道路终点、通行和路面。公开骑行资料将庙前山称为太原西山主峰并给出约 112°19′E、37°47′N 的位置，可作为身份线索，不作为 VELO 路线真值。[庙前山骑行资料](https://club.autohome.com.cn/bbs/thread/c18dc44c9fca17b7/96771073-1.html)

## 全环、反爬和半环现在差什么

八种主脊模式已经写入 `xishan_backbone_route_patterns_v1.json`：南到北全主脊、北到南反爬、南半、北半、经典杜关/偏桥选择、新杜关、枣杜折返、环西山—汾河闭环。

当前不能给全环一个精确公里数，原因不是“没找到更多 Strava 段”，而是四类真实连接还没闭合：天龙山西门—万亩、狼坡—杜关/桃花沟选择口、桃花沟—玉泉主脊、马头水—横岭/二库。完整闭环还多一个二库—汾河/城市返回线。没有这些 provider 几何，报 90、136 或其他数字都只是把官方道路长度、赛事路线和个人骑行 GPX混在一起。

西山旅游公路确实是南北基础设施主轴，公开资料将其描述为连接牛家口与北部、串联大量景点的公路系统；但“136 公里道路系统”“88 公里主线”“一条骑行闭环”是不同对象，不能互相替代。[西山旅游公路建设报道](https://m.thepaper.cn/newsDetail_forward_3838308) [西山旅游公路全线贯通报道](https://m.thepaper.cn/newsDetail_forward_8069587)
