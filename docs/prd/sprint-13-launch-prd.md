## 2. 验收标准(每条二元可判)

- 钟声(D-005):一场约骑中,至少一名半生人完成全链——看到分享卡 → 自己点进来 → 报名 → 到场骑完 → 数据回流留痕,五环节零代办
- 上传体验三拍:选文件(微信聊天记录入口,gpx 和 fit 都能选到)→ 开奖(数据逐项揭晓)→ 成绩卡(可微信原生分享,带「已交卷 m/n」钩子)
- 解析性能(Tim 2026-06-11 拍):上传完成到解析完成 ≤5 秒(常规码表文件),验收=真机连续传 5 个真实文件计时
- 分享卡可从两处发出:约骑详情页(参与者转发)和创建完成页(发起人首发)——审查实证当前详情页没有 onShareAppMessage [✓ grep meetup-detail.js],参与者发不出卡,五环节第一环会断,本期必修
- 时间窗自动关联:约骑当天参与者上传的活动自动挂到该约骑,战报页可见
- 战报页:集体合计 + 照片墙 + 每人一格(按交卷点亮,无名次列)。入口约束的可判定式:战报页不出现在任何 tab 和首页导航,仅分享卡与约骑详情两条路径可达(验收=检查导航配置)
- 天龙山西线在生产环境有完整路书内容
- 生产部署核实:约骑全模块在线上真用走通(commit ≠ ship,服务器停在 2026-05-26 的 93e820e,约骑代码全部在其后 [✓ git log 对照])
