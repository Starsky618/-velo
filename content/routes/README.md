# 路线百科内容目录——Tim 自助修改的唯一入口

> **文案真相源就是这里的 `guide.md`，图片真相源就是这里的图片文件**（2026-06-11 拍 / 2026-06-12 扩展到实景图）：
> VS Code 直接改字、访达直接增删图，LLM 不经手、投影器不覆盖。
> route.json（route skill 工作区）只继续管结构化数据：轨迹坐标、数据指标、证据链。

## 自助发布两步（全程不碰容器、不碰数据库迁移，每一步都可安全重跑）

1. **改内容**：
   - 改文字 → VS Code 打开 `guide.md` 改字保存（`## 模块名` 行别动——前端按它切折叠模块）
   - 改一句话简介 → `meta.json` 里的 highlights
   - 换/加封面 → 把图片命名为 `cover.jpg`（或 .png/.webp）放进路线文件夹，替换旧文件即换图；
     想撤掉封面：删 cover.* 并删 meta.json 里 "cover_url" 那一行
   - **增删实景图 → 直接往路线文件夹里扔图片 / 删图片**（jpg/png/webp 都认）。
     规则一句话：**cover 开头的是封面，其余图片全是实景图**，详情页按文件名排序显示成横滑长廊。
     想控制顺序就在文件名前加 `01_`、`02_`；想撤掉某张就删掉那个文件，meta.json 不用动。
     建议单张 ≤900KB（手机加载快），太大的图发布前可以让 Claude 帮忙压
2. **发布**：双击仓库根目录的 **「发布路线.command」**，终端窗口自动弹出跑完全程（提交→上传图→服务器同步→数据库更新），看到 ✅ 后小程序下拉刷新即见。出错就把窗口截图发给 Claude

## 每个目录里有什么

- `guide.md` —— 正文（**你改这个**）。`## 模块名` 是折叠模块协议：这是一条什么路 / 给真要去的骑友 / 核心数据 / 怎么骑 / 骑友怎么说 / 安全
- `meta.json` —— 卡片元信息（路线名 / 一句话简介 / 图片指针）。改一句话简介改这里的 highlights；
  cover_url / gallery_urls 两个指针由发布脚本自动维护，**不用手改**
- `cover.*` —— 封面图（**你换这个**）
- 其余图片文件 —— 实景图（**你增删这些**），按文件名排序显示
- `track.gpx`（可选）—— 轨迹文件。有它路线就"就绪"：详情页出轨迹地图 + 海拔曲线，约骑可直接选这条路线
