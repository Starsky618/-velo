# 横岭

> 太原骑友的“妙峰山”——11 公里全程大爬坡,本地爬坡赛的主场

## 这是一条什么路

太原骑友管横岭叫“太原的妙峰山”。从汾河边的大留村口拐进尖草坪的山里,一口气爬 11 公里、升 600 多米到横岭村——它是太原少有的“完整赛段”:不像启春阁、天龙山那样半爬半缓,横岭从头到尾都在爬,没有让你歇的平路。

坡度陡一下缓一下,全程大约 3/4 处有一段大陡坡,最大约 18%,是要硬蹬的一段——但横岭真正的难不在某个陡点,而在“11 公里一直爬、不给你歇”。爬上去是放坡,这放坡要命:弯急坡陡,圈刹都刹不住、能闻到刹车皮的味道,摔车、爆胎的不少,山里还常常没手机信号。

它是太原最较真的一条坡——本地车队在这儿办过好几届横岭爬坡赛。能把横岭刷顺,太原的坡你基本都不怵了。

## 给真要去的骑友

- **全段**：起点在汾河滨河绿道的大留村口,往尖草坪山里拐,终点横岭村一带,约 11km / +630m,全程爬坡、没有缓手的平路,进阶级别,新手量力。坡顶有补给点,但山里补给少、部分路段没手机信号——水和干粮带够,别指望山上买、也别指望救援能很快到。放坡极险:弯急坡陡,圈刹容易过热刹不住,下山务必控速、别压弯吃石子(有人压到小石子爆胎、山里没信号冻到等货拉拉)。冬天春天有封山/进山管制、时间不固定,去前务必问本地骑友当天能不能上。想接着玩,可往崛围山飞行基地、阁楼(俯瞰汾河二库)方向串——那是延伸,不算横岭爬坡本体。

## 核心数据

- **距离**：11.0 km
- **累计爬升**：633 m
- **平均坡度**：5.6 %
- **最大坡度**：18 %

## 怎么骑

1. **起点 · 滨河绿道大留村口 → 进尖草坪山** 从汾河边大留村口拐进山开始算爬坡,前段坡度有起伏,陡一下缓一下。
2. **中段 · 11km 持续爬升** 全程在爬,没有让你歇的平路——所以骑友叫它'完整赛段'。海拔从 823m 一路堆到 1400m+。
3. **约 3/4 处 · 一段大陡坡** 最陡的一段不在顶端,在大约全程 3/4 处,最大约 18%,要硬蹬。但它不是全程核心——横岭的难是'11km 一直爬不歇',不是某一个陡点。
4. **延伸 · 崛围山 / 阁楼 / 汾河二库** 登顶后路网可串崛围山飞行基地(滑翔伞)、阁楼(俯瞰汾河二库),是另一段延伸,不算横岭爬坡本体。
- **补给**：坡顶有补给点,但山里补给少、部分路段没手机信号——水和干粮带够,别指望山上买、也别指望救援很快到

## 骑友怎么说

- “放坡圈刹也刹不住,都能闻到刹车皮的味道了,轮都给整热乎了。”——横岭下山的招牌险情——坡太陡、刹车过热
- “太原的坡动不动就十五六、十七八度,陡一下缓一下的。”——横岭就是这种陡缓交替,不是匀速缓爬
- “放坡是快乐,但确实也有点害怕,圈刹也不好刹住。”——老手对横岭放坡又爱又怕
- “下山压到颗小石子就爆胎了,山里还没信号,等货拉拉差点冻死。”——放坡失误的真实代价 + 山里无信号
- “太原反复刷横岭的,估计只有于老师。”——横岭之难,能反复刷的是本地传奇

## 安全

- 放坡极险（招牌）— 弯急坡陡,圈刹容易过热、刹不住(能闻到刹车皮味)。下山务必控速、别压弯吃石子,摔车爆胎的不少。
- 山里没手机信号 — 部分路段无信号,出事难求援(有人爆胎冻到等货拉拉)。结伴去,水和干粮带够。
- 全程无缓手 — 11km 一直爬,进阶级别,新手量力。坡顶有补给点,但山里补给少,自己备够。
- 冬春封山 / 进山管制（属实）— 冬天、春天有封山和进山管制,时间不固定,去前务必问本地骑友当天能不能上山。
